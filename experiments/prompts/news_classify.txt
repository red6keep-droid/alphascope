Return a JSON array with exactly one object per input item, in the same order, keyed by the same "item_id". Output JSON only — no prose, no markdown.

Your job is LABELING, not judgment. Do not estimate how much a stock will move. Do not predict prices. Do not give opinions.

For each item return:
