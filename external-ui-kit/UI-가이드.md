# UI 가이드 (외부 적용용)

AlphaScope 블로그에서 쓰는 화면 규칙 가운데 **UI 규칙만** 떼어 낸 문서입니다. 기사 문체, 리포트 구성, 데이터 표기 같은 콘텐츠 규칙은 뺐습니다.

같은 폴더의 파일:

| 파일 | 용도 |
| --- | --- |
| `UI-가이드.md` | 이 문서. 규칙과 값 |
| `ui-kit.css` | 웹 앱에 바로 붙이는 CSS 변수 + 부품 클래스(`ui-` 접두어) |
| `tokens.json` | 앱 · 디자인 도구용 값 (색, 글자, 여백, 그림자, 모서리) |
| `demo.html` | 부품 견본. 브라우저로 열어 확인 |

값은 2026-10-19 블로그 테마(`alphaflow-home.html` · `build_theme.py`)에서 옮겼습니다. 원본이 바뀌어도 이 폴더는 자동으로 따라가지 않습니다.

---

## 1. 기본 원칙

1. **모바일이 기준.** 360px 폭에서 먼저 확인합니다. 글자를 좁은 칸에 억지로 넣지 않고, 넓은 표 · 그림은 가로 스크롤로 둡니다.
2. **같은 뜻은 같은 모양.** 색 · 크기 · 아이콘을 화면마다 새로 정하지 않습니다. 이 문서의 값만 씁니다.
3. **강조는 카드로.** 중요한 내용을 글자를 키우거나 굵게 해서 강조하지 않습니다. 연한 색 배경 카드에 담습니다.
4. **카드 안에 카드를 만들지 않습니다.** 여러 값은 한 카드 안에서 가로 구분선으로 나눕니다.
5. **여백은 정수 px만.** margin · padding · gap · 크기 · 행간 모두 소수점을 쓰지 않습니다. 퍼센트로 늘리고 줄인 값은 반올림합니다. 예외는 자간, 선 두께, 그림자 번짐, PC 글자 크기입니다.
6. **여백은 "보이는 거리"로 잽니다.** 테두리 · 구분선에서 글자까지 화면에 보이는 거리가 기준입니다. 코드 padding = 목표 거리 − 행간의 반쪽입니다. 예를 들어 글자 19px · 행간 24px이면 반쪽이 약 2px이라, 보이는 14px을 원하면 padding 12px을 줍니다.
7. **색만으로 뜻을 전하지 않습니다.** 색과 함께 ▲▼, 부호, 글자를 같이 씁니다.
8. **로그인 전에는 쓸 수 없는 버튼을 보여 주지 않습니다.** 할 수 있는 사람에게만 동작 버튼을 보입니다.

## 2. 레이아웃

### 2-1. 화면 폭과 구간

| 구간 | 폭 | 바뀌는 것 |
| --- | --- | --- |
| PC | 1181px 이상 | 콘텐츠 폭 980px 가운데, 좌우 여백 40px, 헤더에 메뉴 + 검색창 |
| 태블릿 | 901 ~ 1180px | 좌우 여백 24px, 검색은 아이콘 → 헤더 아래 한 줄로 펼침 |
| 작은 태블릿 | 681 ~ 900px | 메뉴가 오른쪽 서랍으로, 2열 카드가 1열로 |
| 폰 | 680px 이하 | 화면 가장자리 → 콘텐츠: 상세 화면 14px · 대시보드 10px, 제목 2px 작게 |

- 콘텐츠 최대 폭은 **980px**입니다. 헤더 안쪽(로고 · 메뉴)도 같은 980px 선에 맞추고, 헤더 바탕과 아래 선만 화면 전체 폭입니다.
- 헤더 로고 · 아이콘의 좌우 여백은 그 화면 본문의 좌우 여백과 같게 맞춥니다.

### 2-2. 헤더

- 높이 86px, 흰 바탕, 아래 1px `#E2E8F0`, 위에 고정(`position: sticky`).
- 로고: 마크 36×33px + 글자 24px 900굵기, 사이 8px.
- 메뉴: 19px 굵게, 위아래 20px · 좌우 12px, 사이 12px. 마우스를 올리면 액센트 색. **현재 위치는 액센트 색 + 아래 3px 막대**(위 모서리만 3px 둥글게).
- 900px 이하: 높이 자동 · 위아래 12px. 메뉴 · 검색 · 알림은 36px 네모 아이콘 버튼(테두리 `#E2E8F0`, 모서리 8px).

### 2-3. 서랍 메뉴 (900px 이하)

- 오른쪽에서 열림. 폭 `min(320px, 84vw)`, 위 여백 72px, 그림자 `-8px 0 30px rgba(15,23,42,.18)`, 열림 0.22초.
- 메뉴 줄: 18px 굵게, 위아래 14px · 좌우 24px, 줄 사이 1px `#F0F0F0`.
- 뒤 화면을 **어둡게 하지 않습니다.** 투명한 가림막으로 바깥 누르기만 받습니다. 닫기는 × 버튼 · 바깥 누르기 · Esc. 열린 동안 뒤 화면 스크롤을 잠급니다.

### 2-4. 대시보드 (카드 모음 화면)

- 바탕 회색 `#F3F4F6` 위에 흰 카드를 놓습니다. 회색은 헤더 바로 아래부터 화면 전체 폭입니다.
- 카드 사이 20px, 맨 위 카드 위도 20px.
- PC(901px 이상)는 2열 그리드. 전폭 카드는 `grid-column: 1 / -1`.
- 상세 화면(글 보기)은 흰 바탕 한 열입니다.

## 3. 글자

### 3-1. 글꼴

| 용도 | 글꼴 |
| --- | --- |
| 기본 (폰 · 태블릿) | `Noto Sans KR`, 그다음 시스템 글꼴 |
| PC (901px 이상) | 나눔바른고딕(`NanumBarunGothic`), 그다음 Apple SD Gothic Neo · 맑은 고딕. 글자에 `-webkit-text-stroke: 0.25px` |
| 숫자 | `Inter` + `font-variant-numeric: tabular-nums` (자릿수 정렬) |
| 로고 | `Noto Sans KR` 900 |

### 3-2. 크기 · 행간

**폰 · 태블릿 기준** (900px 이하):

| 단계 | 크기 / 행간 | 굵기 | 쓰는 곳 |
| --- | --- | --- | --- |
| 페이지 제목 | 35 / 48 (900px 이하 27 / 36, 680px 이하 23 / 32) | 굵게 | 상세 화면 맨 위 제목 |
| 구획 제목 (**공식 제목**) | 22 / 28, 680px 이하 20 / 26 | 굵게 | 카드 제목, 구획 제목 |
| 본문 | 19 / 34 (카드 안에서는 19 / 24) | 보통 | 문장, 목록, 카드 값 |
| 카드 이름 | 16 / 24 | 굵게 | 구분선이 있는 카드의 왼쪽 이름 |
| 카드 값 | 19 / 24 | 굵게 | 카드 오른쪽 값 |
| 버튼 | 16 / 24 | 굵게 | 큰 버튼 |
| 작은 글 | 14 / 20 | 보통 | 안내, 날짜, 보조 줄, 라벨, 작은 버튼 |

**PC** (901px 이상, 나눔바른고딕은 같은 px에서 더 커 보여 줄였습니다):

| 단계 | 크기 / 행간 |
| --- | --- |
| 페이지 제목 | 28 / 36 |
| 구획 제목 | 18.5 / 23.5 |
| 본문 | 16 / 32 |
| 메뉴 · 탭 | 16 / 22 |
| 카드 값 | 16 / 20 |
| 작은 글 | 14 / 20 (그대로) |

- **굵게는 다섯 곳만:** 제목, 소제목, 카드 왼쪽 이름, 카드 오른쪽 값, 목록 항목의 제목. 문장과 라벨에는 쓰지 않습니다.
- **괄호 부분은 한 단계 작게, 보통 굵기.** `거래량 (20일 평균 대비)`의 괄호는 14px. 괄호는 통째로 줄바꿈합니다(`display: inline-block`).
- **한국어는 어절에서만 줄바꿈** (`word-break: keep-all`). 끊을 곳 없는 긴 영문 · 주소만 강제로 넘깁니다.
- 행간은 px 정수로 적습니다. 14px 글에는 반드시 행간 20px을 같이 줍니다(부모의 큰 행간을 물려받지 않게).

### 3-3. 표기

- `:` 와 `·` 는 **앞뒤를 한 칸씩 띄웁니다.** `라벨 : 값`, `금리 · 지표`. 예외는 시각 `09:30`, 비율, 주소.
- 날짜는 점 표기, 앞자리 0 없이: `2026.10.9`.
- 문장 앞 기호(`·` `•` `-`)로 글머리표를 흉내 내지 않습니다. 4-8의 점 글머리표를 씁니다.
- 줄표(—)는 쓰지 않습니다.

## 5. 카드

### 5-1. 카드 종류

| 종류 | 바탕 / 테두리 | 모서리 | 그림자 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| **대시보드 카드** | 흰색 / 1px `#F3F4F6` | 12px | 있음 (5-2) | 회색 바탕 위 큰 카드 |
| **콘텐츠 카드** | 흰색 / 1px `#E2E8F0` | 8px | 없음 | 흰 바탕 위 값 목록, 표 대신 쓰는 카드 |
| **강조 카드** | 상태 색 연한 배경 / 같은 계열 테두리 (4-4) | 10px | 없음 | 결론, 상태, 꼭 봐야 할 한 가지 |
| **기본 카드** | `#F8FAFC` / `#E2E8F0` | 10px | 없음 | 핵심 한 줄, 휴무 · 빈 상태 안내 |
| **안내 상자** | `#FFF8E1` / `#F4D37A` | 10px | 없음 | 시험 운영 · 공지 |
| **목록 카드 (클릭)** | 흰색 / 1px `#F0F0F0` | 16px | 올리면 생김 | 글 목록 카드 |

### 5-2. 그림자

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 카드 (아주 옅게) | `0 10px 22.5px -5px rgba(0,0,0,.029), 0 8px 9px -6px rgba(0,0,0,.029)` | 대시보드 카드 |
| 카드 올림 | `0 6px 24px rgba(15,23,42,.07)` + `translateY(-2px)` | 클릭 카드에 마우스를 올렸을 때 |
| 팝업 | `0 12px 40px rgba(0,0,0,.25)` | 가운데 팝업 |
| 떠 있는 상자 | `0 8px 30px rgba(15,23,42,.18)` | 아래 안내 시트, 서랍 |
| 펼친 검색창 | `0 8px 24px rgba(15,23,42,.14)` | 헤더 아래 검색 줄 |
| 눌린 칸 | `0 1px 3px rgba(0,0,0,.12)` | 전환 버튼의 선택 칸 |

그림자는 대시보드 카드 · 떠 있는 것에만 씁니다. 흰 바탕 위 콘텐츠 카드는 테두리만 씁니다.

### 5-3. 대시보드 카드 안쪽

- 안쪽 여백 위아래 16px · 좌우 10px.
- **카드 머리**: 제목(아이콘 + 글자) 왼쪽, 날짜 · 안내 글 오른쪽(14px 회색). 위 14px · 아래 13px, 아래 1px `#E5E7EB` 구분선.
- 카드 안 구분선과 내용은 머리 구분선과 같은 폭 — 카드 안쪽에서 좌우 16px 더 들어갑니다.

### 5-4. 줄 카드 (이름 · 값)

- 줄마다 **이름 왼쪽, 값 오른쪽.** 이름 16px 굵게 `#111`, 값 19px 굵게, 증감 값만 상태 색.
- 칸 비율 **왼쪽 65% · 오른쪽 35%.** 한 카드의 값이 모두 5자 미만이면 80% · 20%. 넘치면 글자를 줄이지 않고 어절에서 줄을 바꿉니다.
- **오른쪽 끝은 항상 숫자.** 설명 글자와 ▲▼는 숫자 앞에 둡니다: `현재가 대비 ▲ 43.4%`.
- 증감 값 묶음(기호 + 숫자 + 단위)은 줄바꿈하지 않습니다.
- 줄 사이 1px `#E2E8F0`. 구분선 위아래 보이는 거리 **22px**, 카드 가장자리도 22px.
- 이름 아래 보조 줄: 14px `#7A7A7A`.
- 한 줄에 칸 여러 개(통계 줄): 칸마다 이름 14px 회색 위 · 값 17px 굵게 아래, 가운데 정렬, 칸 사이 세로 1px 구분선.

### 5-5. 보이는 위아래 여백

| 카드 | 보이는 위 · 아래 |
| --- | --- |
| 강조 카드 | 24px (카드 안 구분선 위 · 아래 14px) |
| 구분선이 있는 콘텐츠 카드 | 22px (구분선 위 · 아래도 22px) |
| 기본 카드 | 14px |
| 안내 상자 | 12px |
| 펼침 버튼 줄 | 10px |

좌우 여백은 12 ~ 14px로 둡니다.
