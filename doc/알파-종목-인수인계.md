# 알파 종목 리포트 — 인수인계 (2026-09-24)

새 채팅에서 이어가기 위한 요약. 이 문서와 [알파-종목-리포트-기획.md](알파-종목-리포트-기획.md)를 먼저 읽는다.

## 목표

`reference2/doc/`의 AlphaFlow 명세(호재·미디어 언급 + 가격 반응 = 알파 종목)를 바탕으로,
**알파 종목을 매일 찾아 블로그에 올리고 3일·5일 뒤 성적을 자동 추적하는 리포트**를 만든다.
환경: GitHub Actions + Blogger + Gemini, DB 없음(state 브랜치), 공개 리포.

## 사용자 결정

- 유니버스: **S&P 500 + 지수 밖 대형주(시총 ≥ $10B, ADR 포함) ≈ 940종목, 섹터 중심**. 안정성 우선.
- 보유: 3일 · 5일 비교, 손절 −7% / 목표 +10% 병행.
- 리포트의 핵심: **호재가 있는 강한 장에서 며칠 연속 상승하는 종목을 찾는 것.**
- `index.html`(블로거 테마) 업로드는 나중에 한 번에 사용자가 직접 한다.

## 지금까지 확인된 사실 (experiments/signal-study, 500종목 · 2016~2026)

1. MRH 가격 조건 5개(당일 +5~12% · RVOL ≥ 2 · 종가 상위 25% · 섹터 ETF > 20일선 · 5일 누적 < +20%)만으로 사면
   5일 승률 50.3% vs 같은 종목 무작위 날 51.7% (p 0.87). **가격 조건 단독은 정보가 없다.**
2. 표본 크기 문제 아님: 느슨한 규칙 13,345건도 50.4%. 3일→5일 되돌림도 없음(평균 누적 T+1 +0.07% → T+5 +0.38%).
3. 52주 신고가 · IT 섹터 · 다음날 확인 진입 모두 유의한 개선 없음.
4. **5일 연속 상승(+8%↑)은 6,018건(연 ~560건)으로 흔하다.** 그러나
   - 완성 후 사면 5일 승률 48.2%, 평균 −0.29% (나쁨)
   - 스트릭 **첫날은 조용했다**: 상승률 중앙값 +2.0%, +5% 이상은 11%, RVOL ≥ 2는 6%.
   → MRH 규칙은 연속 상승 종목의 89%를 첫날 걸러낸다. 대형주의 "급등 + 거래량 폭발"은 하루짜리 뉴스 충격 모양이다.

## 다음에 할 일 (이전 제안 — 위 계획 문서로 대체됨)

지금 캐시된 데이터(`experiments/signal-study/data/bars.pkl`)로 바로 검증 가능한 것:

1. **섹터 하향식** — 섹터 ETF 5D·20D 상대강도 상위 3 섹터 × 섹터 대비 상대강도 상위 종목. 3·5·20일 보유. 플라시보 비교.
2. **보유 기간 확장** — 52주 신고가 + 섹터 강세 종목의 20·60일 보유 (대형주 모멘텀은 1~12개월 구간).
3. **눌림 진입** — 뉴스 충격일 이후 2~3일 되돌림에서 진입.

결과에 따라 기획 문서 3절(판정)을 "급등 발굴"에서 **"강한 섹터의 주도 종목 + 지속형 촉매"**로 바꾼다.
뉴스 촉매를 "단발(실적·등급) / 지속(가이던스·계약·제품·규제·테마)"로 나누는 것도 반영할 것.
