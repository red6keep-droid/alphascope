## 2. 작업 순서 (Claude 확정, 위임)

| # | 작업 | 내용 | 블로그 영향 |
|---|---|---|---|
| W1 | 맨 위 한 줄 | 분석 단계에 EWMA σ(λ 0.94, 실적일 제외) · z · "1년에 몇 번 오는 날"(지난 252일 \|z\| 이상 비율) 계산 → 가격 카드 바로 아래 한 줄. 평소 범위 안 = 한 줄, 밖 = 크기 + "S&P 500 종목 기준, 평소 국면의 이런 날은 사고팔기에 아무 날과 다르지 않았다" | 글 본문 |
| W2 | 시장 충격 표시 | VIX 종가 ≥ 35 시작 · < 25 끝을 상태 브랜치에 기억 → 맨 위 표시 + A3 기록 문장 · 흔들림 가라앉는 시간(초기 5일 배수별 13 · 36 · 52일 + 범위) | 글 본문 |
| W3 | 관점 둘 | 같은 글 안에 보유자 · 살 사람 문장 둘 다 넣고 테마에서 고르게 할지, 문장을 둘 다 짧게 나란히 둘지 — 초안 두 개로 비교 | 테마일 수 있음 |
| W4 | 근거층 · 채점 | 근거는 기존 ? 툴팁(`tip_icon`)에. 발행 때 맨 위 한 줄 값 저장(state_io) → 다음 거래일 채점 · 월 1회 근거층 공개 | 상태 브랜치 |
| W5 | 분기 점검 넓히기 | 재무 탭 점검표에 지수 대비 흔들림 · 비중 산수 · 같이 움직이는 종목 | 글 본문 |
| W6 | 해석 금지 | narrate 프롬프트 · 검증에 "전망 · 그래서 오를 것 · 사라 / 팔라" 금지 추가 | 글 본문 |
| W7 | 정리 | 경계값 문구 · 경고색 · 제거 확정 항목 반영, 디자인 가이드라인 갱신 | 글 본문 |

W1 · W2 는 기존 구획을 지우지 않고 추가로 먼저 만든다(로컬 미리보기). 제거 항목은 사용자 확인 뒤 W7 에서.
