# 엔비디아(NVDA) 리포트 — 주가 영향 이벤트 정의와 포착 가능성

작성 2026-10-07. 3년 보유 중인 NVDA 한 종목에 대해 **매일 리포트**를 만들기 위한 첫 단계.
"주가에 영향을 줄 만한 이벤트"를 먼저 자유롭게 나열하고, 각 이벤트를 **우리가 자동으로 포착해 매일 리포트에 쓸 수 있는가**를 정의한다.
설계 원칙은 트럼프 리포트와 같다. 숫자는 코드가 만들고, Gemini는 분류와 문장만 맡는다. 투자 권고 표현은 쓰지 않는다.

## 0. 결론 요약

- 이벤트 후보 **12개 영역, 약 45개 항목**을 뽑았다 (1절).
- 포착 방식은 다섯 등급으로 나뉜다 (2절). 매일 값이 바뀌어 **일일 섹션**이 되는 것은 시세·거래량·옵션·내부자 공시·뉴스룸·애널리스트·트럼프 이벤트 7개뿐이다. 나머지는 **캘린더(D-n)**, **공시 트리거(발생 시만)**, **분기 누적표**로 들어간다.
- "스마트 머니"는 공개 데이터로는 **13F(45일 지연)·Form 4(2영업일)·ETF 발행주식수·공매도 잔고(반월)** 네 개로만 근사된다. 기관 실시간 순매수·다크풀은 유료라 **제외**한다. 대신 거래량 배수와 옵션 미결제약정 변화를 대리 지표로 쓴다.
- 법정 공방·규제는 빈도가 낮다. 매일 수집하되 **변화가 있는 날만** 리포트에 올리고, 평소엔 "진행 중 사안 N건, 변동 없음" 한 줄로 끝낸다.
- 매일 리포트의 뼈대는 3절. **"오늘 바뀐 것 → 다가오는 것 → 상태판 → 보유 논리 점검표"** 순서다.

## 2. 포착 가능성 정의

### 2-1. 등급

| 등급 | 뜻 | 리포트에서의 자리 |
| --- | --- | --- |
| **A 일일 자동** | 공개 소스, 매일 값이 바뀜, 코드로 수집 | 상태판 (매일 숫자) |
| **B 캘린더** | 날짜를 미리 안다 | D-n 카운트다운 + 발생 후 결과 요약 |

### 2-3. 수집 비용 추정

- HTTP 호출: yfinance 수 회 · EDGAR 3회 · Federal Register 1회 · CourtListener 1회 · RSS 4~5개 · ETF 페이지 2개 · TSMC 월 1회. **키 필요 없음** (CourtListener 토큰은 무료 발급).
- Gemini: 외부 뉴스·연방관보·법원 문서 분류 **하루 20~40건 1배치** + 서술 1회. 트럼프 리포트보다 적다.
- 실행 시간: 1분 내외 예상. GitHub Actions 일일 스케줄 가능 (trump-trend 워크플로 복제).

## 3. 매일 리포트 뼈대 (초안)

```
엔비디아 데일리 — YYYY년 M월 D일

① 오늘 한 줄            종가·등락·SPY/SMH 대비·거래량 배수. (코드 생성)

③ 다가오는 것           B등급 D-n 목록 (실적·고객사 실적·TSMC 월매출·FOMC·GTC·리밸런싱). 7일 이내만.
④ 상태판                A등급 숫자표: 기술 · 옵션(IV 랭크·P/C·implied move) · 추정치 7일 변화 ·
                        애널리스트 분포 · ETF 발행주식수 5일 변화 · 공매도 잔고(최근 회차)
⑤ 진행 중 사안          규제·소송 추적 목록. 상태(진행/대기/종결)·마지막 변동일. 변동 없는 날은 접힘.
⑥ 보유 논리 점검표      분기 갱신 누적표: 하이퍼스케일러 capex 가이던스 · 데이터센터 매출 성장률 ·
                        총마진 · 중국 매출 비중 · TSMC 월매출 YoY · 자사주 매입 · 13F 상위 보유 변화
```

- ②가 비는 날이 많아야 정상이다. 트럼프 리포트에서 배운 대로, **억지로 헤드라인을 채우지 않는다.**
- ⑥은 3년 보유자가 실제로 보는 표다. 매일 안 바뀌지만 매일 싣는다. "이 표의 어느 칸이 꺾였나"가 이 리포트의 존재 이유.
- Gemini 서술은 ②의 문장과 ⑥의 분기 코멘트에만 쓴다. 숫자는 전부 코드.

## 4. 열어 둔 결정

1. **13F 파싱을 1차에 넣을지.** 지연 45일이라 "스마트 머니"로서의 가치가 낮다. 1차는 yfinance `institutional_holders`(상위 10, 분기)로 대체하고 보류 제안.
2. **실적 콜 녹취록 소스.** 무료 안정 소스가 없다. 1차는 보도자료 + 10-Q로 가고, 녹취록은 수동 첨부 가능하게만.
3. **게시 여부와 주기.** 매일 자동 생성은 하되, 블로그 게시는 트럼프 리포트처럼 그림자 모드로 시작. 매일 글이 너무 비면 주간 게시로 전환.
4. **이벤트 → 반응 통계를 넣을지.** 종목 하나라 표본이 적다. 트럼프 이벤트(25번)만 기존 통계를 가져오고, 나머지는 통계 없이 사실만 기록. 1년치 쌓인 뒤 재검토.
5. **임계값.** 2-2의 숫자는 전부 초안. 첫 30일 돌려 보고 ②에 하루 평균 1~3건 올라오도록 조정.
