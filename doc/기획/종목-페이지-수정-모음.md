# 종목 페이지 수정 모음 (한꺼번에 적용용)

사용자가 "수정 사항 알려 줄 테니 계속 저장하고 있어, 한꺼번에 수정할게"(2026-10-26)라고 한 요청을 번호로 쌓는다. **적용 · 목업은 "적용해" 하라고 할 때 한 번에 한다.** 적용한 뒤에는 `적용` 칸에 날짜를 적고, 공통 규칙은 디자인-가이드라인 · 변경 이력에 옮긴다. 홈 요청은 [홈-수정-모음](홈-수정-모음.md)(H번호)에 따로 둔다.

보고 있는 목업: 한국 종목 `experiments/kr-stocks/output/mock_005930.html`(삼성전자, 10-23 종가).
