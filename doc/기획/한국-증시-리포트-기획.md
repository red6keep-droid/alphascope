## 0. 이 리포트의 자리

| | 언제 | 무엇 |
|---|---|---|
| 미국 증시 리포트 (데일리) | 한국 아침 07:00 | 밤사이 미국 + 한국장 탭 = **오늘 한국장 준비** |
| **한국 증시 리포트 (이 문서)** | 한국 장 마감 뒤 16:10 | **오늘 한국장 정리** — 무슨 일이 있었고, 왜 그렇게 열렸고, 평소보다 컸나 |
| 한국 시총 상위 10 목록 페이지 | 매일 갱신 (고정 페이지) | 지금 상태판 — 순위 · 시장 흐름 카드 9개 |

- 목록 페이지와 겹치지 않게: 리포트는 **날짜가 붙은 글**(지난 날을 다시 볼 수 있고, "코스피 마감" 검색에 걸린다) · **오늘 하루를 설명**한다. 시장 흐름 카드 9개 전부를 옮기지 않고 그날 움직인 것만, 나머지는 목록 페이지 링크.
- 아침 리포트와 짝: 아침에 "밤사이 미국이 얼마나 닿나" 를 말했으면 저녁엔 "실제로 시가에 얼마나 닿았고 장중엔 어땠나" 로 닫는다.

## 1. 독자 · 막는 실패

- 독자: 국내 주식 계좌를 가진 사람 (국내 독자가 먼저 — 종목 레이더 10절과 같음).
- 막는 실패 (목적 조사 6절을 국내에 옮김):
  - 크게 빠진 날 장 마감 뒤 공포 매도 결심 · 크게 오른 날 다음 날 아침 추격 매수
  - "외국인 ○조 매도" 같은 숫자 하나에 과잉 반응 (검증: 외국인 누적은 이후 수익과 관계 없음)
  - 시가 갭을 장중 흐름으로 착각 (검증: 밤사이 미국 몫은 시가에서 끝남)

## 2. 질문 (Claude 확정 — 사용자 목업 확인 뒤 수정)

| 질문 | 답의 성격 | 근거 |
|---|---|---|
| R1. 오늘 코스피 · 코스닥은 평소와 달랐나 | 평소 범위 (데일리 D3 과 같은 자, EWMA) | 사실 · 설명 |
| R2. 왜 이렇게 시작했고, 장중엔 어땠나 | 하루 = **시가 갭(밤사이 미국 몫) + 장중(한국장 몫)** 으로 나눠 보여 줌 | K24 · K25 검증 통과 — 효과는 시가 갭에서 끝 |
| R3. 큰 종목들은 어떻게 움직였나 | 시총 상위 10개를 평소 범위 기준 크게 움직인 순 + 미국과 연결 종목 밤사이 (검증 통과 종목만) | K17 ① 35종목 중 20개 통과 |
| R4. 어느 묶음이 움직였나 | 반도체 · 2차전지 · 바이오 · 방산 · 조선 · 원전 평균 vs KOSPI | 사실 |
| R5. 누가 사고팔았나 | 외국인 일별 · 20일 누적 (상태만), 거래대금 열기 | 기록상 "이후와 관계 없음" 을 그대로 적음 |
| R6. 환율 · 금리는 | 원/달러 · 국고채 (상태만) | 같음 |
| R7. 앞으로 무엇이 오나 | 14일 안 시장 일정(미국 FOMC · CPI 등, 국내 옵션 만기) · 상위 10개 실적일 + 그날 보통 움직임 | 데일리 D5 와 같은 형식 |
| R8. 오늘 한국 증시 방송은 무엇을 말했나 | 방송 줄 (media_feed 한국 채널) — 헤드라인체 | 뉴스 형식 통일 6절 |

**시총 상위 10개 주가 그 자체(시세표)는 주인공이 아니다** — 목적 문서 7절 "가격 알림에 가깝지 않은가". R3 처럼 "평소보다 컸나 · 밤사이 미국과 연결" 이 붙을 때만 쓴다.

## 3. 적용 기준

- A1 앞날 문장 금지. `기록상` 은 검증 통과한 것만: 밤사이 EWY · SOX · VIX · 달러지수 → 다음날 KOSPI, 미국과 연결 종목 → 다음날 종목 (모두 "시가에서 끝남" GAP_NOTE 와 함께).
- A2 관계 없던 것(외국인 누적 · 환율 · 금리차 · 거래대금 급증)은 값만 + 기록상 "관계 없음" (universe_kr.NO_RECORD 문구 그대로).
- A3 평범한 날 = 한 줄. 평소 범위 안이면 "평소 범위 안" 으로 끝, 밖이면 크기 + 1년에 몇 번.
- A4 장중 되돌림을 "반등 신호" 로 쓰지 않는다 — 사실로만 ("낮게 시작해 장중 +2.7% 올라 마감").
- A5 법: 매수 · 매도 표현 없음, 운영자 보유 비공개, 국내 종목도 사실 · 기록만.
- A6 문체: 합니다체 (design_kit.formal), 방송 줄은 헤드라인체.

## 6. 위험 · 남은 결정

- ECOS 외국인 일별이 16:10 에 그날 값이 있는지 미확인 → 없으면 그 카드는 "전일 기준" 으로 표시 (첫 실행 로그로 확인).
- 비슷한 글 반복(색인 탈락) — 평범한 날은 짧게(A3), 제목에 날짜.
- yfinance 약관(D4-7) — 미국과 같은 결함, 유료 전환으로 함께.
- 발행 순서: 미국 새 15페이지(10-27 끝) → 한국 종목 첫 발행(KR_PUBLISH, 10-27 사용자 "그렇게 해") → 그다음 이 리포트 (KR_REPORT_PUBLISH, 확인 뒤).
- 남은 사용자 결정: 목업 보고 뺄 것 · 바꿀 것, 발행 시작 시점.
