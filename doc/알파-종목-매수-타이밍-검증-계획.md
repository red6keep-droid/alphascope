## 0. 목표

> **승률을 위한 정확한 매수 타이밍을 안다.**

사용자가 정한 네 갈래 (2026-09-24):

1. **상승을 포착**하고 다음 날 매수 → 보유 기간별 승률
2. **눌림을 포착**하고 매수 → 보유 기간별 승률
3. 두 가지의 전제: **연속 상승이 며칠 가능했는지**
4. **섹터의 움직임**(기술·금융·에너지 등 순환, 자금 흐름)을 고려한 타이밍

리포트 운영 방식은 이 문서의 관심사가 아니다. 결과가 나오면 그때 [기획 문서](알파-종목-리포트-기획.md) 3·4절에 반영한다.

### 승률만 보면 틀린 결론이 나온다 — 함께 보는 지표 (2026-09-24 추가)

| 지표 | 계산 | 왜 |
| --- | --- | --- |
| 손익비 | 평균 이익 ÷ 평균 손실 (비용 후) | 승률 60%인데 이익 +1% · 손실 −3%면 손해 |
| 기대값 | 승률 × 평균 이익 − 패율 × 평균 손실 | 한 번 살 때 기대 수익. 승률과 손익비를 합친 값 |
| 최대 역행폭 (MAE) | 진입가 대비 청산 전까지 최저가의 손실률 (중앙값 · 90% 분위) | 승률이 같아도 중간에 −6%까지 갔다면 나쁜 타이밍. "정확한 타이밍" 목표에 직접 닿는 지표 |
| 진입 갭 | T+1 시가 ÷ T 종가 − 1 (중앙값 · 분포) | 신호가 이미 가격에 반영됐는지. 승률이 안 나오는 이유를 설명 |
| 기준선 대비 차이 | 승률 − 기준선 승률 (%p) | **표에서 굵게 표시하는 값.** 보유가 길면 승률은 저절로 오르므로 절대값은 보지 않는다 |
| 하루 신호 수 | 신호일 기준 하루 평균 · 신호 없는 날 비율 | 1년에 3번이면 못 쓰고 하루 200개면 못 고른다 |

### 섹터 조건 (확정)

사용자 요구: *"섹터별 움직임, 순환되는 스마트 머니의 흐름도 알아야 한다."*

"스마트 머니"는 직접 볼 수 없다. 가격·거래량에 남은 흔적으로 추정하며, 다음 지표를 **ETF(시총 가중 = 대장주)와 종목 동일가중(= 평균 종목) 둘 다**로 만든다.

| 지표 | 계산 | 뜻 |
| --- | --- | --- |
| 섹터 상대강도 | 섹터 지수 ÷ SPY의 20일·60일 변화 | 돈이 옮겨 가는 방향 |
| 순환 국면 (RRG 방식) | 상대강도 수준 × 상대강도 변화 → 주도 · 약화 · 소외 · 개선 | 사이클 위치 |
| 섹터 폭 | 섹터 종목 중 20일선 · 50일선 위 비율 | 섹터 전체인지 소수인지 |
| 거래대금 흐름 | 상승일 거래대금 − 하락일 거래대금, 20일 누적 | 매수 자금 축적 |
| ETF − 동일가중 괴리 | 두 지수 수익률 차 | 대장주 쏠림 |

**확정 (2026-09-24, 권고대로):**

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 전환 이벤트 정의 | **(a) 상대강도 20일 음→양 · (c) 섹터 폭 50% 상향 돌파 · (d) 섹터 지수 자기 200일선 회복 — 셋 다 계산해 비교** | (b) RRG 개선→주도는 국면 라벨로만 쓴다 |
| 적용 방식 | **(나) 분할** — 전부 계산하고 국면별로 나눠 표시 | 효과가 확인되면 필터로 승격 |
| 섹터 지수 | **ETF와 동일가중 둘 다** | 대장주 vs 평균 종목 |

## 3. 검증 항목과 순서

각 항목의 규칙 목록은 **결과를 본 뒤 추가하지 않는다.** 추가가 필요하면 8절에 기록하고 새 회차로 돌린다.

### 공통 분할 축

모든 표는 다음 축으로 나눠 볼 수 있게 계산한다. 단, **채택 판정은 전체 표본에서만** 하고 분할은 방향 확인용이다 (4절 검정력).

| 축 | 값 | 이유 |
| --- | --- | --- |
| 구간 | 탐색 2016~2022 / 검증 2023~ | 과최적화 방지 |
| 연도 | 2016 ~ 2026 | 한 해가 전체를 끌어올렸는지 |
| **실적 인접** | 실적 발표 ±1 거래일 / 그 외 | 실적 후 지속 상승(PEAD)은 대형주 단기 모멘텀이 성립하는 거의 유일한 자리. 실적 없는 급등은 하루짜리 뉴스 충격일 가능성. **섹터 국면보다 더 크게 갈릴 수 있는 축** |
| 섹터 국면 | 주도 · 약화 · 소외 · 개선 (⓪에서 생성) | 사용자 4번 |
| 섹터 | 11개 | 섹터별 성격 |
| **공포** (2026-09-24 추가) | VIX < 15 / 15~20 / 20~30 / > 30 | 공포 구간에서 눌림이 더 잘 되나 |
| **금리 방향** | 10년 금리(^TNX) 20일 변화 상승 / 하락. 장단기 차(^TNX − ^IRX) 정상 / 역전 | 금융·유틸·부동산 순환의 원인 변수 |
| **위험 선호** | HYG − LQD 20일 상대수익 양 / 음 | 신용 시장이 위험을 받아들이는가 |
| **유가** | WTI(CL=F) 20일 변화 상승 / 하락 | 에너지·소재 순환의 원인 변수 |
| 거시 (월간) | 실업률 · CPI · 기준금리 — 방향(전월 대비) | 월 1회 갱신이라 며칠 단위 타이밍에는 약함. ⓪ 순환의 배경 설명용 |

축이 늘수록 칸이 얇아진다 (4절 검정력). **채택 판정은 전체 표본, 축은 방향 확인용** 원칙을 유지한다.
**r01에는 거시 축 중 공포(VIX)와 금리 방향 둘만** 분할 축으로 넣고, 위험 선호·유가·월간 거시는 ⓪-7에서만 본다 (확정 2026-09-24).

### 순서

⓪ 섹터 순환은 가장 복잡하고 목표와의 거리가 가장 멀다. ① 연속 상승은 단순한 서술 통계라 먼저 돌려도 다른 검증을 오염시키지 않고,
모멘텀/반전 방향을 알려 ②·③의 비중을 정하는 근거가 된다. **⓪과 ①을 같은 회차(r01)에 함께 돌린다** (확정 2026-09-24).

**질문:** 섹터가 강해지기 시작하는 시점을 알 수 있나. 그때 들어가면 의미가 있나. 순환에 순서가 있나.

| ⓪-4 | **종목 진입** — 전환일 다음 날 시가에 그 섹터 종목 매수 (전체 / 섹터 안 상대강도 상위 3). 보유 3·5·10·20일 승률 vs 기준선 |
| ⓪-5 | **진입 지연** — 전환 당일 / 3일 뒤 / 5일 뒤 진입 비교 |
| ⓪-6 | **순환 순서** — 섹터 간 전환의 선행·지연 (교과서 순서: 금융·경기소비 → 기술·산업 → 에너지·소재 → 유틸·필수소비·헬스케어 가 데이터에 있는가) |
| ⓪-7 | **원인 변수와의 관계** — 금리 상승 구간에 금융이, 유가 상승 뒤 며칠 만에 에너지가 주도 국면으로 가는가 (선행·지연) |

산출: 각 (섹터, 거래일)의 **국면 라벨** → ①~③의 분할 축.

### ① 연속 상승 (전제 — 사용자 3번)

**질문:** 연속 상승은 며칠 이어지나. k일 연속 오른 뒤 다음 날도 오를 확률은.

**확정:** 상승일 = **종가 > 전일 종가** (2026-09-24).

| 표 | 내용 |
| --- | --- |
| ①-1 | 스트릭 분포 — 1·2·3·4·5·6·7일 이상 이어진 건수·비율 |
| ①-2 | **지속 확률** — k일 연속 상승 뒤 다음 날도 오를 확률 (k=1~7) vs 무조건 확률. 모멘텀인지 반전인지 여기서 갈린다 |
| ①-3 | 첫날 상승률 구간(+0~1 / +1~3 / +3~6 / +6%↑)별 스트릭이 3일·5일까지 가는 비율 |
| ①-4 | **진입 위치별 성적** — k일 연속 상승 확인 후 다음 날 시가 매수 (k=1~5) × 보유 6개. 승률·평균, 기준선 대비 |

공통 분할 축 적용. ①-4에는 2절 7번 지표(손익비 · 기대값 · MAE · 진입 갭 · 하루 신호 수)를 모두 붙인다.

### ② 상승 포착 → 다음 날 매수 (사용자 1번)

| 코드 | 신호 (T일 마감) |
| --- | --- |
| U1 | 당일 +3~6% |
| U2 | 당일 +6~12% (MRH 유사, 대조군) |
| U3 | 당일 +3%↑ 이고 RVOL ≥ 1.5 |
| U4 | 2일 연속 상승, 누적 +4%↑ |
| U5 | 20일 신고가 마감 |
| U6 | 20일 신고가 마감 이고 종가 > 50일선 |

보유 6개 + 규칙 청산 2개: **첫 하락 마감 다음 날 시가 매도** · 손절 −7% / 목표 +10%. 공통 분할 축 적용 — 특히 **실적 인접 여부**로 반드시 나눈다.

**미결:** ① 결과를 보고 규칙을 조정할지 (①에서 반전이 확인되면 ②의 비중을 줄이고 ③에 집중).

### ③ 눌림 포착 → 매수 (사용자 2번)

추세(공통): 종가 > 50일선 이고 20일선 > 50일선.

| 코드 | 눌림 신호 |
| --- | --- |
| P1 | 20일 고점 대비 −3~−8% 상태에서 당일 종가 > 전일 종가 |
| P2 | 5일선 아래 1~3일 마감 뒤 5일선 위로 복귀한 날 |
| P3 | 3일 연속 하락 뒤 첫 상승일 |
| P4 | 급등일(+5%↑ · RVOL ≥ 2) 뒤 2~5일 안에 −2~−6% 되돌림 후 상승 마감 ("뉴스 충격 후 눌림") |
| P0 | 대조: 추세 조건 없이 3일 연속 하락 뒤 첫 상승일 |

보유 6개 + 규칙 청산: **5일선 아래로 마감하면 다음 날 시가 매도**. 공통 분할 축 적용.

### ④ 섹터 조건 결합 (사용자 4번)

①~③에서 살아남은 규칙마다:
- 소속 섹터 국면(주도·개선·약화·소외)별 성적
- 섹터별 성격 — 11개 섹터 각각에서 상승 포착과 눌림 중 어느 쪽이 맞나 (통념: 에너지 반전, 기술 추세)
- ⓪의 전환 이벤트 직후 N일 안의 종목 신호 vs 그 외

### ⑤ 종합

통과한 규칙만 **"모양 → 진입 → 보유 → 섹터 조건"** 한 장의 표로. 통과한 것이 없으면 그것이 결과 — "가격 모양만으로는 승률을 못 올린다"가 확정되고 힘은 호재 쪽에서 와야 한다.

통과한 규칙이 하루에 여러 종목을 내면 **고르는 순서**(RVOL순 · 상승률순 · 섹터 내 상대강도순)를 한 번 비교한다. 상위 5개로 잘랐을 때 승률이 유지되는지가 실용성의 기준이다.

통과한 것이 있으면 다음 단계는 (1) 940종목 대형주에서 재확인 → (2) 리포트에 그림자 모드로 기록 → (3) 30건 쌓인 뒤 실제 성적과 비교.

### 채택 기준

| 항목 | 값 |
| --- | --- |
| 구간 | 탐색 2016~2022 / 검증 2023~. 탐색에서 고르고 검증에서 확인 |
| 채택 (거래 단위) | 승률 차이 **+3%p 이상** · p < 0.05 · **탐색·검증 양쪽 모두** |
| 채택 (날짜 단위) | **날짜 단위에서도 기준선을 이겨야 한다** — 아래 "신호는 독립이 아니다" |
| 보조 — 연도 안정성 | 10년 중 **기준선을 이긴 해가 7년 이상.** 2021년 한 해가 전체를 끌어올린 경우를 걸러낸다 |
| 보조 — 기대값 | 기대값 > 기준선 기대값. 승률만 높고 손익비가 나쁜 규칙 제외 |
| 기준선 | 같은 종목 무작위 날 (필수). 같은 날 다른 종목 (보조 — 시장 타이밍 효과 분리) |
| 중복 | 같은 종목에서 보유 기간 안 재신호는 첫 건만 |
| 현실적 상한 | 대형주 가격 모양만으로는 **+3~5%p**가 상한에 가깝다. 60~70%가 나오면 오류를 먼저 의심 |

### 검정력 — +3%p를 잡으려면 칸당 약 1,000건

승률 차이 +3%p를 95% 신뢰로 구분하려면 **칸당 약 1,000건**이 필요하다. 100건이면 오차 ±10%p라 +3%p는 보이지 않는다.

- 섹터 11 × 국면 4 × k 5 × 보유 6으로 나누면 칸 대부분이 100건 아래로 떨어진다. **그 칸은 방향만 볼 수 있고 채택 근거로 못 쓴다.**
- 따라서 순서를 **"전체 표본에서 효과 확인 → 통과한 것만 나눠 보기"**로 고정한다. 나눈 칸에서 우연히 좋은 것을 고르면 다중 검정에 걸린다.
- `MIN_N = 300`: 이 아래 칸은 결과 표에서 회색(`†`)으로 표시하고 숫자를 해석하지 않는다. 1,000 아래는 `‡`로 "방향만".

### 신호는 독립이 아니다 — 날짜 단위 통계

같은 날 200종목에 신호가 뜨면 그건 200개의 관측이 아니라 **"그날 시장이 올랐다" 한 개**다. 종목별로 세면 p가 실제보다 훨씬 작아진다.

- 신호일마다 그날 신호 종목의 평균 수익을 **하나의 관측**으로 보고, 같은 날 기준선(그 종목들의 무작위 날 기대값 · 그날 전체 유니버스 평균)과 비교한다.
- 표에 **"기준선을 이긴 날 비율"**과 날짜별 차이의 **t 통계량**을 넣는다. 지난 섹터 검증의 "무작위보다 나은 날" 열이 이것이다.
- 다중 검정: 조합이 100개를 넘으면 우연히 5개는 유의. 검증 구간 통과 + 날짜 단위 통과를 필수로 두어 막는다.
