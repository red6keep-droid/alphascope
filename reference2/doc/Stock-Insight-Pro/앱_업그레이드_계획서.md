# Stock Insight Pro V7.2 핵심 리스크 엔진 업그레이드 계획서
본 계획서는 1인용 미국 주식 퀀트 비서 시스템 **Stock Insight Pro**의 리스크 엔진을 V6.3(V3.0)에서 **V7.2**로 업그레이드하기 위한 핵심 아키텍처 정의 및 설계 문서입니다.

---

## 1. 개요 및 배경 (Overview & Context)
기존 V6.3 엔진은 기계적인 지표 계산과 정량적 매크로 페널티 감점으로 인해 두 가지 고질적인 문제를 안고 있었습니다:
1. **과도한 매매 잠금 (Over-Locking):** 매크로 악재가 이중 감점되어 유망한 주도주까지 기계적으로 매수가 금지(`NO TRADE`)되는 현상.
2. **단일 로직 한계 (One-Size-Fits-All):** 거래 유동성과 파생 상품(옵션) 데이터가 풍부한 S&P 500 대형주와 상대적으로 가격 변동성 중심인 일반 중소형주가 동일한 로직으로 필터링되어 분석 노이즈가 발생하는 현상.

**V7.2 핵심 리스크 엔진**은 S&P 500 대형주와 일반 종목의 데이터 특성을 반영하는 **이원화 분기 구조**, **매크로의 신뢰도 마커 전환**, **추세 면책 특권** 및 **수급 감쇄 로직**을 적용하여 **"생존 우선(Survival Over Alpha)"**의 철학을 고도화하면서도 불필요한 매매 잠금을 획기적으로 개선합니다.

---

## 2. 6대 핵심 업그레이드 설계 (Core Architecture Specifications)

### ① 데이터 처리 '이원화 분기 구조' (Dual-Path Data Processing)
*   **목적:** S&P 500 대형주와 일반 종목의 수급/파생 데이터 풍부도 차이를 연산 속도와 정확도에 반영합니다.
*   **재해석 및 구현 방안:**
    *   서버 실행 시점에 S&P 500 티커 목록을 기반으로 고속 판정이 가능한 `SP500_SET`을 메모리에 구성($O(1)$ 복잡도).
    *   **경로 A (S&P 500 대형주):** 다크풀(Darkpool), 감마 플립 가격(Gamma Flip), FINRA 일일 공매도 비율, 내부자 거래(SEC Form 4) 등 파생/수급 계량 모델을 탑재한 **정밀 필터링(전략 A)**을 수행합니다.
    *   **경로 B (일반 종목 및 ETF):** 수급 데이터의 누락 및 노이즈가 많으므로, 불필요한 데이터 탐색을 배제하고 **순수 가격, 지지 매물대, 상대적 변동성(ATR) 중심의 필터링(전략 B)**을 적용합니다.

### ② 배후 매크로 지표의 '신뢰도 마커' 전환 (Macro to Confidence Marker)
*   **목적:** 금리(^TNX)나 달러인덱스(DXY) 악재를 개별 종목 점수에서 직접 감점하는 다중공선성 오류를 제거하여, 과도하게 매매가 정지되는 현상을 방지합니다.
*   **재해석 및 구현 방안:**
    *   기존의 `penalty += 0.30` 형식의 매크로 직접 감점 구조를 완전히 삭제합니다.
    *   매크로 상태는 엔진이 현재 장세를 평가하는 `regimeConfidence` ('Low' / 'Medium' / 'High') 신뢰도 마커의 백그라운드 값으로만 투영합니다.
    *   개별 종목의 상대강도가 강력하다면 매수를 허용하되, 매크로 신뢰도가 'Low'인 경우 투자 비중(Sizing)을 보수적으로 낮추도록 제안하는 가이드를 제공합니다.

### ③ S&P 500 전용 4대 수급/파생 레이어 결합 (전략 A 전용)
*   **목적:** 대형 기관들의 자금 이동 및 파생 포지션 장벽을 실시간 추적하여 강력한 수학적 방어선을 구축합니다.
*   **재해석 및 구현 방안:**
    *   **감마 리스크(isGammaRisk):** 당일 종가가 감마 플립선(`gammaFlipPrice`) 아래에 있으면 숏 스퀴즈 붕괴 및 매도 압력 가속 구역으로 판정하여 리스크 가중치를 부여합니다.
    *   **공매도 비중(dailyShortRatio):** FINRA 일일 공매도 비중이 임계치(예: 25%)를 지속적으로 초과하면 패널티 가산.
    *   **다크풀 매집(darkpoolSpike):** 장외 대량 거래(Dark Pool Volume) 폭발 신호를 감지하여 대형 세력 개입 여부 분석.
    *   **내부자 거래(isCEOBuy / isCFOBuy):** SEC Form 4 공시 기반의 임원진 장내 매수 여부를 가산 방어 포인트로 매핑합니다.

### ④ '추세 면책 특권' 및 '수급 감쇄 로직' 구현 (Immunity & Attenuation)
*   **목적:** 대세 상승장 주도주가 기술적 지표(RSI 과열) 때문에 기계적으로 매매 대상에서 제외되는 현상을 방지하고, 강력한 수급 유입 시 조기 진입을 허용합니다.
*   **재해석 및 구현 방안:**
    *   **추세 면책 특권:** 주가 추세 강도 지표인 `ADX > 25`이면서 주가가 20일/50일 이평선 위의 정배열(강세 레짐) 상태라면, `RSI > 70` 이상에서 가해지던 '과열 패널티'를 **0점 처리**하여 면제합니다.
    *   **수급 감쇄 로직:** 주가가 중요 매물대 지지선에 걸친 상태에서 기관의 다크풀 대량 매집(`darkpoolSpike === true`)이 포착되거나 내부자 장내 매수가 확인될 경우, 해당 종목에 축적된 **누적 패널티 점수를 최종적으로 50% 감쇄**(`penalty *= 0.5`)하여 빠른 진입을 승인합니다.

### ⑤ 임계치(Threshold)의 '상대적 규격화(Normalization)'
*   **목적:** 가격과 등락폭이 천차만별인 500개 이상의 미국 주식 종목들을 단일 임계값으로 필터링할 때 발생하는 왜곡을 해결합니다.
*   **재해석 및 구현 방안:**
    *   **변동성 임계 규격화:** "5% 하락 시 경보" 같은 절대 수치 대신 `ATR_5D / ATR_90D` 배수를 사용하되, 종목의 역사적 변동성 등급에 따라 고변동성 주식은 `1.7`배, 저변동성 주식은 `1.4`배 등으로 규격화하여 작동시킵니다.
    *   **수급 상대적 강도:** 단순 등락폭 대신 `(개별종목 5일 수익률) - (SPY 지수 5일 수익률)` 연산 방식을 적용하여 시장이 빠져도 버티거나 올라가는 상대적 '청개구리 방어주(Outperformer)'를 자동 구별해 냅니다.

### ⑥ 추적 로그 'Trace Log' 데이터 구조 고도화
*   **목적:** 원천 데이터와 최종 결과값 사이에서 발생할 수 있는 논리적 오류를 신속히 찾고 디버깅할 수 있도록 정교한 로깅을 구현합니다.
*   **재해석 및 구현 방안:**
    *   연산 함수 시작점에 `traceLogs: Array<{ ruleId: string, label: string, detail: string, impact: number }>` 구조의 로컬 배열을 이식합니다.
    *   리스크 필터 연산이 진행되며 각 조건식 분기가 발동될 때마다 최종 패널티 점수뿐만 아니라, **어떤 룰에서 어떤 임계치 비교를 통해 점수가 왜 할당되었는지** 실시간 매핑 데이터와 함께 고스란히 저장해 프론트엔드 분석 뷰로 전달합니다.

## 3. 실제 앱 코드 이식을 위한 "하방 호환성" 재해석 설계

사용자님의 지적대로, 단순 개념 사양 코드를 기계적으로 복사-붙여넣기 하면 우리 앱의 **기존 데이터 모델 및 렌더링 컴포넌트(InsightCard, MacroDashboard, Sandbox 등)와 맞물리지 않아 대규모 컴파일/런타임 에러가 발생**합니다.

따라서, 우리 앱의 실제 파일들인 [src/engine/stockRiskEngine.ts](src/engine/stockRiskEngine.ts)와 [src/engine/riskEngine.ts](src/engine/riskEngine.ts)의 구조에 완벽하게 호환되도록 재해석하여 이식을 설계해야 합니다.

---

### ① [재해석 1] stockRiskEngine.ts (Zustand 스토어 & 백엔드 연동)

이 파일은 백엔드 서버([server.ts](server.ts)), 상태 관리자([src/store/useQuantStore.ts](src/store/useQuantStore.ts)), 개별 종목 카드([src/components/InsightCard.tsx](src/components/InsightCard.tsx))에서 주입받아 직접 호출됩니다. 하방 호환성을 유지하기 위해 **기존 입력 타입(`StockRiskInput`)을 유지한 채 선택적 속성(`ticker`)을 추가**해 정밀 이원화 구조를 타도록 재해석했습니다.

```typescript
// S&P 500 티커 O(1) 초고속 식별을 위한 정적 해시 셋 정의
const SP500_SET = new Set([
  'AAPL', 'MSFT', 'NVDA', 'GOOGL', 'GOOG', 'AMZN', 'META', 'TSLA', 'BRK.B', 'LLY', 'AVGO', 'JPM', 'UNH', 'NKE'
  // ...연동 시 S&P 500 전 종목 매핑 가능
]);

export type ActionZone = '파일럿 진입 (Pilot Buy)' | '소규모 진입 (Small Size)' | '보수적 관망 (Hold)' | '철저히 관망하세요 (NO TRADE)' | '정상 진입 (Normal Buy)';

export interface StockRiskInput {
  ticker?: string;          // ★ [V7.2 추가] 이원화 분기를 위한 선택적 티커 주입
  macroRegime: string;      // From market (e.g. NORMAL, VOLATILE, PANIC_SELL, FAKE_REVERSAL)
  vixValue?: number;        // Real market VIX (from ^VIX)
  
  stock: {
    atr5d: number;
    atr90d: number;
    rsValue: number;        // ETF 대비 상대강도 (개별 5일 수익률 - SPY 5일 수익률)
    trendSlope: number;     // 주가 추세
    adx?: number;           // 추세 강도
    rsi?: number;           // ★ [V7.2 추가] 추세 면책 특권용 RSI 수치
    isAtSupportZone?: boolean; // ★ [V7.2 추가] 수급 감쇄용 지지선 도달 여부
    fundamentalScore?: number; // 펀더멘털 점수
  };

  flow: {
    shortVolumeRatio: number;
    darkPoolSpike: boolean;
    insiderScore: number;   // e.g. Buy - Sell (CEO/CFO 포함)
    gammaFlipPrice?: number; // ★ [V7.2 추가] S&P 500 전용 감마 플립선 가격
  };

  dataIntegrity: {
    hasPriceData: boolean;
    hasVolData: boolean;
    hasFlowData: boolean;
  };
}

export const calculateStockRisk = (input: StockRiskInput) => {
  let penalty = 0;
  const explanations: any[] = [];
  let actionZone: ActionZone = '정상 진입 (Normal Buy)';
  
  const vix = input.vixValue || 20; 
  const adx = input.stock.adx || 20;
  const ticker = input.ticker?.toUpperCase() || '';
  const isSP500 = SP500_SET.has(ticker);

  // 0. 자가 신뢰도 시스템 (Data Integrity) - 기존 호환성 보장
  let missingCount = 0;
  if (!input.dataIntegrity.hasPriceData) missingCount += 1;
  if (!input.dataIntegrity.hasVolData) missingCount += 1;
  if (!input.dataIntegrity.hasFlowData) missingCount += 1;
  
  const confidenceScore = 1.0 - (missingCount * 0.33);
  
  if (confidenceScore <= 0.6) {
    return {
      actionZone: '철저히 관망하세요 (NO TRADE)' as ActionZone,
      penaltyPercent: 100,
      confidenceScore,
      explanations: [{
        ruleId: 'RULE_INTEGRITY_FAIL',
        label: '데이터 신뢰도 부족',
        detail: '필수 원천 데이터(수급, 가격변동 등)가 충분하지 않아 매매를 강제 금지합니다.',
        impact: 100
      }],
      meta: { macroRegime: input.macroRegime, isVolatilityExpanding: false, ruleSet: 'V7.2_Integrity' }
    };
  }

  // 1. 배후 매크로 지표의 '신뢰도 마커(Confidence Marker)' 평가
  let regimeConfidence: 'HIGH' | 'MEDIUM' | 'LOW' = 'MEDIUM';
  if (vix > 30 || input.macroRegime.includes('PANIC') || input.macroRegime === 'FAKE_REVERSAL') {
    regimeConfidence = 'LOW'; // 매크로 지표 이탈 시 직접 penalty 가중치 더하는 것 대신 신뢰도 마커 하향
  } else if (vix < 18 && input.macroRegime === 'NORMAL') {
    regimeConfidence = 'HIGH';
  }

  // 2. 임계치의 상대적 규격화 (Normalization)
  let isVolatilityExpanding = false;
  if (input.stock.atr90d > 0) {
    // 종목 성격별 변동성 임계 규격화
    const dynamicAtrThreshold = input.stock.atr90d > 5.0 ? 1.7 : 1.4;
    isVolatilityExpanding = (input.stock.atr5d / input.stock.atr90d) > dynamicAtrThreshold;
    if (isVolatilityExpanding) {
      penalty += 0.25;
      explanations.push({
        ruleId: 'RULE_VOLATILITY_SPIKE',
        label: '종목 변동성 임계 한도 초과',
        detail: `최근 ATR 변동 비율(${(input.stock.atr5d / input.stock.atr90d).toFixed(2)}배)이 규격 한도(${dynamicAtrThreshold}배)를 초과하여 브레이크 작동`,
        impact: 25
      });
    }
  }

  // 3. 데이터 처리 이원화 분기 구조 실행
  if (isSP500) {
    // ==========================================
    // [전략 A] S&P 500 파생/수급 중심의 정밀 필터
    // ==========================================
    
    // A-1. 감마 플립선 이탈 여부 평가
    const currentPrice = input.stock.trendSlope; // 가격 정보 호환 바인딩 혹은 실시간 주가 대입
    if (input.flow.gammaFlipPrice && currentPrice > 0 && currentPrice < input.flow.gammaFlipPrice) {
      penalty += 0.30;
      explanations.push({
        ruleId: 'RULE_A_GAMMA_FLIP',
        label: '기관 구조 지지선 이탈 (감마 리스크)',
        detail: `S&P 500 대형주 현재가가 Gamma Flip Price ${input.flow.gammaFlipPrice} 미만 구역에 위치함 (매도 압력 가속화)`,
        impact: 30
      });
    }

    // A-2. FINRA 일일 공매도 비율
    if (input.flow.shortVolumeRatio >= 25.0) {
      penalty += 0.15;
      explanations.push({
        ruleId: 'RULE_A_SHORT_RATIO',
        label: '공매도 과밀 리스크',
        detail: `FINRA 일일 공매도 비중 ${input.flow.shortVolumeRatio}% 도달 (기관 매도 저항선 형성)`,
        impact: 15
      });
    }

    // A-3. 다크풀 대량 거래
    if (input.flow.darkPoolSpike) {
      penalty += 0.10;
      explanations.push({
        ruleId: 'RULE_A_DARKPOOL',
        label: '다크풀 기관 손바뀜 포착',
        detail: '장외 블록딜 및 대규모 다크풀 거래량 급증 포착 (일시적 노이즈 위험)',
        impact: 10
      });
    }

  } else {
    // ==========================================
    // [전략 B] 일반 소형주/중소형주 가격/상대강도 중심 필터
    // ==========================================
    
    // B-1. 시장 대비 극심한 소외 감지 (상대강도 Normalization)
    if (input.stock.rsValue < -2.0) {
      penalty += 0.20;
      explanations.push({
        ruleId: 'RULE_B_RELATIVE_WEAKNESS',
        label: '시장 대비 극심한 자금 소외',
        detail: `지수(SPY) 대비 5일 상대 수익률 ${input.stock.rsValue.toFixed(2)}% 기록 (상대강도 전강후약)`,
        impact: 20
      });
    }

    // B-2. 역배열 하락 추세 감지
    const dynamicAdxTh = vix > 25 ? 22 : 18;
    const isWeakTrend = adx < dynamicAdxTh;
    const isDowntrend = input.stock.trendSlope < 0;

    if (isWeakTrend || isDowntrend) {
      const trendPenalty = isDowntrend ? 0.20 : 0.10;
      penalty += trendPenalty;
      explanations.push({
        ruleId: 'RULE_B_TREND_FALL',
        label: '역배열 추세 미달',
        detail: isDowntrend ? '주가 5일 추세 기울기 하락(Downtrend)' : `추세 신뢰도 부족 (ADX ${adx} < 기준치 ${dynamicAdxTh})`,
        impact: Math.round(trendPenalty * 100)
      });
    }
  }

  // 4. '추세 면책 특권 (Trend Immunity)' 적용
  if (input.stock.rsi && input.stock.rsi > 70) {
    const isStrongTrend = adx > 25 && input.stock.rsValue > 1.0;
    if (isStrongTrend) {
      // 강력한 상승 주도주는 RSI 과열 패널티를 0점 처리 (면책 특권)
      explanations.push({
        ruleId: 'RULE_IMMUNITY_RSI',
        label: 'RSI 과열 면책 특권 부여',
        detail: `RSI ${input.stock.rsi} (과열)이나 강력한 시장 아웃퍼폼(ADX ${adx})으로 매수 타당성 인정`,
        impact: 0
      });
    } else {
      penalty += 0.20;
      explanations.push({
        ruleId: 'RULE_RSI_OVERBOUGHT',
        label: '기술적 과열 경보',
        detail: `RSI ${input.stock.rsi} 상태로 단기 과매수 이탈 리스크 누적`,
        impact: 20
      });
    }
  }

  // 5. '수급 감쇄 및 펀더멘털 방어 (Attenuation)' 적용
  const hasSmartMoney = input.flow.darkPoolSpike || input.flow.insiderScore > 0;
  const isFundamentalStable = (input.stock.fundamentalScore !== undefined && input.stock.fundamentalScore >= 80);

  if ((input.stock.isAtSupportZone && hasSmartMoney) || isFundamentalStable) {
    if (penalty > 0) {
      const originalPenalty = penalty;
      // 수급 주입 시 50% 감쇄, 우량 펀더멘털 시 25% 감쇄
      const reductionRatio = (input.stock.isAtSupportZone && hasSmartMoney) ? 0.50 : 0.75;
      penalty *= reductionRatio;

      const reducedPoints = Math.round((originalPenalty - penalty) * 100);
      explanations.push({
        ruleId: 'RULE_ATTENUATION_SUCCESS',
        label: hasSmartMoney ? '기관 수급 기반 패널티 감쇄' : '우량 펀더멘털 안전 보장 감쇄',
        detail: hasSmartMoney 
          ? `주가 매물 지지선 부근에서의 세력 및 임원진 매집으로 리스크 총점 ${reducedPoints}P 차감`
          : `우량 펀더멘털 스코어(${input.stock.fundamentalScore}점) 승인에 따른 기계적 페널티 완화`,
        impact: -reducedPoints
      });
    }
  }

  // 최종 행동 등급 도출 (우리 앱의 기존 3단계 ActionZone 매핑 그대로 유지)
  const penaltyPercent = Math.min(Math.round(penalty * 100), 100);
  
  if (penaltyPercent >= 50) actionZone = '철저히 관망하세요 (NO TRADE)';
  else if (penaltyPercent >= 25) actionZone = '보수적 관망 (Hold)';
  else if (penaltyPercent > 0) actionZone = '소규모 진입 (Small Size)';
  else if (regimeConfidence === 'LOW') actionZone = '파일럿 진입 (Pilot Buy)';
  else actionZone = '정상 진입 (Normal Buy)';
  
  // 마켓 레짐 강제 오버라이드
  if (input.macroRegime === 'PANIC_SELL' || input.macroRegime === 'FAKE_REVERSAL') {
    actionZone = '철저히 관망하세요 (NO TRADE)';
  }

  return {
    actionZone,
    penaltyPercent,
    confidenceScore,
    regimeConfidence, // ★ [V7.2 추가]
    explanations,     // ★ [V7.2 호환] 기존 설명을 트레이스 로그로 자동 공유
    meta: {
      isVolatilityExpanding,
      macroRegime: input.macroRegime,
      flowScore: hasSmartMoney ? 1 : 0
    }
  };
};
```

```typescript
export const calculateRobustConviction = ({ ticker, stock, macro, smartMoney, eventOptions }: EngineInput) => {
  let penalty = 0;
  const explanations: any[] = [];
  const events = eventOptions || { isEarningsSurprise: false, hasPositiveNews: false, hasNegativeNews: false };
  const currentTicker = ticker?.toUpperCase() || '';
  const isSP500 = SP500_SET.has(currentTicker);

  // 1. 배후 매크로 지표의 '신뢰도 마커' 평가
  let regimeConfidence: 'HIGH' | 'MEDIUM' | 'LOW' = 'MEDIUM';
  const currentVix = macro.vix || 20;
  const isCreditStress = (macro.hySpread !== undefined && macro.hySpread >= 6);

  if (currentVix >= 30 || isCreditStress || macro.fearAndGreed! >= 80) {
    regimeConfidence = 'LOW'; // 직접 penalty 누적 대신 백그라운드 신뢰도 하락
  } else if (currentVix < 18 && macro.fearAndGreed! < 50) {
    regimeConfidence = 'HIGH';
  }

  // 2. 임계치 상대적 규격화 (Normalization)
  let isVolatilityExpanding = false;
  if (stock.atr90d > 0) {
    const atrRatio = stock.atr5d / stock.atr90d;
    const dynamicAtrThreshold = stock.atr90d > 5.0 ? 1.7 : 1.4;
    isVolatilityExpanding = atrRatio > dynamicAtrThreshold;
    if (isVolatilityExpanding) {
      penalty += 0.25;
      explanations.push({
        ruleId: 'RULE_B_VOLATILITY',
        label: '종목 변동성 임계 한도 초과',
        detail: `최근 ATR 배수(${atrRatio.toFixed(2)}배)가 규격 임계 배수(${dynamicAtrThreshold}배) 초과`,
        impact: 25
      });
    }
  }

  const relativeStrength = stock.return5d - macro.spyReturn5d;

  // 3. 데이터 처리 이원화 분기
  if (isSP500) {
    // ==========================================
    // [전략 A] S&P 500 파생/수급 중심의 정밀 필터
    // ==========================================
    
    // A-1. 감마 리스크 평가
    if (smartMoney.gammaFlipPrice && stock.return5d < smartMoney.gammaFlipPrice) {
      penalty += 0.30;
      explanations.push({
        ruleId: 'RULE_A_GAMMA_FLIP',
        label: '기관 구조 지지선 이탈',
        detail: `S&P 500 주가가 Gamma Flip Price ${smartMoney.gammaFlipPrice}를 하회함`,
        impact: 30
      });
    }

    // A-2. 일일 공매도 비율
    if (smartMoney.dailyShortRatio && smartMoney.dailyShortRatio >= 25) {
      penalty += 0.15;
      explanations.push({
        ruleId: 'RULE_A_SHORT_RATIO',
        label: '공매도 과밀 리스크',
        detail: `공매도 비중 ${smartMoney.dailyShortRatio}% 기록으로 매도 저항 증폭`,
        impact: 15
      });
    }
  } else {
    // ==========================================
    // [전략 B] 일반 종목 및 소형주 가격 필터
    // ==========================================
    if (relativeStrength < -2.0) {
      penalty += 0.20;
      explanations.push({
        ruleId: 'RULE_B_RELATIVE_WEAKNESS',
        label: '시장 대비 극심한 소외',
        detail: `시장(SPY) 대비 5일 상대수익률 ${relativeStrength.toFixed(2)}% (자금 이탈)`,
        impact: 20
      });
    }
  }

  // 4. 추세 면책 특권 (RSI 무력화)
  const rsiValue = stock.rsi || 50;
  const adxValue = stock.adx || 20;
  if (rsiValue > 70) {
    const isStrongTrend = adxValue > 25 && relativeStrength > 1.0;
    if (isStrongTrend) {
      explanations.push({
        ruleId: 'RULE_IMMUNITY_RSI',
        label: 'RSI 과열 면책 특권 발동',
        detail: `RSI ${rsiValue} (과열)이나 강력한 추세(ADX ${adxValue}) 형성으로 감점 무력화`,
        impact: 0
      });
    } else {
      penalty += 0.20;
      explanations.push({
        ruleId: 'RULE_RSI_OVERBOUGHT',
        label: '기술적 과열 경보',
        detail: `RSI ${rsiValue} 기준으로 단기 과매수 구역 이탈 발생`,
        impact: 20
      });
    }
  }

  // 5. 수급 감쇄 및 펀더멘털 방어
  const isAccumulating = smartMoney.darkpoolSpike || smartMoney.isCEOBuy;
  const isFundamentalStrong = (stock.fundamentalScore !== undefined && stock.fundamentalScore >= 80);

  if ((stock.isAtSupportZone && isAccumulating) || isFundamentalStrong) {
    if (penalty > 0) {
      const originalPenalty = penalty;
      const reductionRatio = (stock.isAtSupportZone && isAccumulating) ? 0.50 : 0.75;
      penalty *= reductionRatio;

      const reducedPoints = Math.round((originalPenalty - penalty) * 100);
      explanations.push({
        ruleId: 'RULE_ATTENUATION_SUCCESS',
        label: isAccumulating ? '기관 수급 기반 패널티 감쇄' : '펀더멘털 안전 보장 감쇄',
        detail: isAccumulating 
          ? `지지선 지지 및 기관 다크풀/내부자 거래 승인으로 리스크 총점 ${reducedPoints}P 차감`
          : `우량 펀더멘털 안전 보장으로 기계적 페널티 완화`,
        impact: -reducedPoints
      });
    }
  }

  // 6. 최종 행동 지침 (Action Zone) 도출 및 리턴
  const penaltyPercent = Math.min(Math.round(penalty * 100), 100);
  let actionZone: ActionZone = '정상 진입';

  if (penaltyPercent >= 50) actionZone = '강제 진입 금지';
  else if (penaltyPercent >= 25) actionZone = '보수적 관망';
  else if (penaltyPercent > 0) actionZone = '소규모 진입';

  const finalScore = Math.max(Math.round(stock.baseTechnicalScore * (1 - (penaltyPercent / 100))), 0);

  return {
    finalScore,
    penaltyPercent,
    actionZone,
    regimeConfidence, // ★ [V7.2 추가]
    explanations,
    meta: {
      isStockHighRS: relativeStrength > 1.2,
      isVolatilityExpanding,
      flowScore: isAccumulating ? 1 : 0
    }
  };
};
```

## 4. 디버깅 및 개발 파이프라인 (Developer Experience & Testing Loop)

사용자님이 구상하신 **[원천 데이터 주입 ➡️ 결과 도출 ➡️ 중간 연산 로그 노출 ➡️ 예상 수치 대조 및 튜닝]** 디버깅 루프가 V7.2 핵심 엔진에 어떻게 이식되는지 입출력 스펙과 함께 구체화합니다.

### ① 파이프라인 단계별 엔진 내 매핑 상태

*   **[1단계] 원천 데이터 주입 (Data Injection):**
    *   엔진 함수가 실행될 때 개별 종목의 가격/기술 지표 뿐만 아니라, 매크로 마커와 S&P 500 전용 파생/수급 데이터셋을 단일 주입 객체(`RiskEngineInput`)로 통째로 수용하여 입력 인터페이스를 심플하게 통일했습니다.
*   **[2단계] 결과 도출 (Result Derivation):**
    *   연산이 완료되면 가공되지 않은 점수가 아닌, 최종 액션 지침(`actionZone`), 감점률(`penaltyPercent`), 그리고 매크로 신뢰도(`regimeConfidence`)를 한데 묶은 결과 그릇(`RiskEngineOutput`)을 정밀 산출합니다.
*   **[3단계] 중간 연산 로그 노출 (Trace Logging):**
    *   결과를 반환할 때 계산 프로세스의 핵심인 `traceLogs` 배열을 함께 출력합니다. 어떤 규칙(`ruleId`)을 왜 통과했는지, 그 당시 원천 수치가 얼마였고 페널티가 몇 점 가감되었는지가 투명하게 담겨 나옵니다.
*   **[4단계] 예상 수치 대조 및 오차 튜닝 (Interactive Tuning):**
    *   개발자는 수집된 실제 수치와 `traceLogs`에 기록된 연산 수치를 시각적으로 상호 대조하여, 조건식의 누락이나 임계치 한계(Threshold)의 오류 지점을 백엔드 코드나 샌드박스 UI 상에서 즉시 미세 튜닝(Micro-Tuning)할 수 있습니다.

## 5. 실행 및 배포 단계 계획 (Implementation Roadmap)
1. **1단계 (문서 합의 및 백업):** 본 업그레이드 계획서를 확정하고, 기존 리스크 계산 모듈인 [src/engine/riskEngine.ts](src/engine/riskEngine.ts) 및 [src/engine/stockRiskEngine.ts](src/engine/stockRiskEngine.ts)의 오리지널 코드를 안전한 저장소에 백업합니다.
2. **2단계 (서버 파이프라인 데이터 증설):** `server.ts` 내의 [Yahoo Finance] 및 [FINRA API] 연동부에서 `gammaFlipPrice`, `dailyShortRatio`, `isInsiderBuy` 변수가 리스크 계산 요청 바디에 누락 없이 수집되어 전송되는지 확인합니다.
3. **3단계 (이원화 분기 스위치 테스트):** S&P 500 목록에 포함된 `AAPL` 분석 시에는 파생 레이어(감마플립 등)가 완벽히 계산되고, 소형주인 `PANW` 등은 순수 기술적 변동성 비율로 오차 없이 전환되는지 콘솔 로그로 대조합니다.
4. **4단계 (UI 시각화 업그레이드):** 설정 페이지의 **개발자 시뮬레이터(Sandbox)**와 **의사결정 보조 시스템(Decision OS)** 화면에서 V7.2 `traceLogs` 배열의 객체들을 순회하여 어떤 룰이 펜 패널티를 깎거나 더했는지를 타임라인 형태로 시각화해 줍니다.
