# Phase 3: Portfolio & Market Data

사용자의 자산 정보와 종목별 실시간 시세를 연동하는 단계입니다.

## 1. 한국투자증권(KIS) API 이식
- **파일**: `src/api/kis.ts`
- **중요 로직**: 
  - **OAuth 토큰 갱신**: 24시간마다 만료되는 토큰을 자동으로 관리하는 `getAccessToken()` 함수.
  - **계좌 조회**: 보유 종목 리스트, 매입 단가, 현재가 정보를 가져오는 기능.

## 2. 해외 시세 데이터 (TwelveData)
- **파일**: `src/api/twelveData.ts`
- **역할**: KIS에서 제공하지 않는 세부 보조지표나 실시간 차트 데이터를 보강할 때 사용합니다.

## 3. 데이터 캐싱 전략
- **파일**: `data_cache.json` 관리 로직.
- API 호출 횟수 제한(Rate Limit)을 피하기 위해 로컬 스토리지나 파일에 데이터를 일시 저장하는 기능을 구현합니다.

## 4. 종목 상태 관리
- **파일**: `src/store/useQuantStore.ts` 내 `stocks` 배열 관리 로직.
- 종목 추가, 삭제, 즐겨찾기 기능이 상태 저장소와 연동되도록 합니다.

## ✅ 검증 포인트
1. KIS API를 통해 내 실제 계좌의 종목들이 리스트업되는가?
2. 실시간 시세가 15분~1시간 주기로 정확히 업데이트되는가?
3. 브라우저를 새로고침해도 보유 종목 리스트가 유지되는가?
