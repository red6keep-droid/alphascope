# AlphaFlow 보유자산(Holdings) 엔진 및 UI 명세서 V1.0

본 문서는 Stock-Insight-Pro의 복잡한 자산 관리 기능을 AlphaFlow의 '에너지 추적' 철학에 맞춰 정화하고 간소화하여 재설계한 명세서입니다.

---

## 1. 핵심 설계 원칙 (Core Principles)
1. **용어의 정화:** RSI, ADX, SL/TP 등 기술적 영문 용어를 폐기하고 '과열도', '상승 힘', '에너지 상태' 등 쉬운 한국어로 대체한다.
2. **에너지 중심:** 종목의 결함을 찾아 매매를 통제(Lock)하는 대신, 현재 보유한 종목의 '상승 에너지'가 여전히 유효한지를 판독하여 제공한다.
3. **고밀도 정보:** 모바일 화면에서 한눈에 내 수익률과 에너지를 확인할 수 있도록 여백을 최소화한 콤팩트 디자인을 적용한다.

---

## 2. 주요 기능 및 로직 (Functional Specs)

### 2.1 통합 자산 관리 (Simplified Portfolio)
* **데이터 입력:** 티커, 매수 평단가($), 보유 수량만 입력받는 초간결 모달.
* **실시간 수익 추적:**
  * **수익률:** `(현재가 - 평단가) / 평단가 * 100` (한국어로 '수익률' 표기)
  * **평가 손익:** `(현재가 - 평단가) * 수량` (한국어로 '수익금' 표기)
* **영속성:** 브라우저 로컬 스토리지 또는 Firebase User 컬렉션에 동기화.

### 2.2 실시간 에너지 감시 (Energy Monitor)
복잡한 7대 지표를 계산하는 대신, 이미 구현된 **Layer 3 에너지 판독기**를 보유자산에 실시간 적용한다.
* **상태 배지 (Mandatory):**
  * **에너지 확인됨 (Confirmed):** 퀀트 요건 충족 및 상승 에너지 유지 중.
  * **주의/관찰 (Warning):** 단기 급등 후 과열 징후 포착.
  * **에너지 소멸 (Exhausted):** 주요 지지선 이탈 또는 거래량 급감 (매도 고려 신호).
  * **신규 탐지 (New):** 최근 내러티브가 발생한 초기 단계.

### 2.3 내러티브 연결 (Context Linking)
* 해당 종목을 왜 샀는지 잊지 않도록, 최근 AI가 분석한 **'핵심 투자 내러티브'**를 카드 하단에 한 줄 요약으로 상시 노출한다.

---

## 3. UI/UX 구성 (High-Density UI)

### 3.1 보유자산 종목 카드 (Holdings Card)
* **헤더:** 종목명(한글), 티커, 현재가, 전일대비 등락률.
* **중간 레이어 (자산 현황):**
  * 평단가 vs 현재가 비교.
  * 큰 폰트(18px)의 **수익률(%)** 및 색상 적용 (상승: 빨강, 하락: 파랑).
* **하단 레이어 (에너지 판독):**
  * 현재 에너지 상태 배지.
  * 퀀트 엔진의 판단 근거 (예: "기관 수급 유지 중", "과열권 진입 주의").

### 3.2 탭 구성
* **[인텔리전스]:** AI 시그널 탐색 및 분석.
* **[성과 검증]:** 과거 시그널의 적중률 및 Alpha 확인.
* **[보유자산] (NEW):** 내 실제 포트폴리오의 에너지 상태 실시간 모니터링.

---

## 4. 데이터 파이프라인 (Data Pipeline)
* **시세 데이터:** `CollectorService`를 통해 Yahoo Finance 실시간 데이터 활용.
* **판독 로직:** `QuantService.validateFactors()`를 호출하여 실시간으로 `energy_status`와 `decision_logs` 획득.
* **UI 업데이트:** React Query 또는 로컬 상태 관리를 통해 가격 변동 시 수익률 즉시 갱신.
