# 통합 초과 수익률 분석 (Integrated Alpha Analysis) 가이드

## 1. 개요 (Overview)
**통합 초과 수익률 분석** 페이지는 AI가 추출한 투자 시그널이 실제 시장에서 어떤 성과를 거두었는지 정량적으로 검증하는 AlphaFlow의 핵심 엔진입니다. 단순히 정보를 나열하는 것을 넘어, **'뉴스 기반 시그널'**과 **'퀀트 필터링 시그널'**의 성과 차이를 A/B 테스트 방식으로 증명합니다.

## 2. 핵심 메뉴 구성 (Main Tabs)

### 2.1 순수 뉴스 시그널 (Pure News Signals)
- **대상:** AI 분석 엔진을 통해 추출된 모든 초기 시그널.
- **용도:** 필터링 전의 원본 데이터 성과를 확인하여, 시장 내러티브의 초기 반응을 모니터링합니다.

### 2.2 승인 엔진 통과 (Quant Approved)
- **대상:** 퀀트 승인 엔진(Quant Approval Engine)의 엄격한 필터를 통과한 고신뢰 시그널.
- **통합 지원:** 일반 뉴스 시그널뿐만 아니라 **'당잠사', '매드머니' 브리핑에서 추출된 종목**도 필터 조건 충족 시 이 카테고리에 포함됩니다.
- **필터 조건:**
    - **거시 지표 (VIX):** 공포 지수(VIX)가 25 미만인 안정적인 시장 환경에서만 승인.
    - **거래 대금 (Dollar Volume):** 유동성 리스크를 방지하기 위해 일정 수준 이상의 거래 대금이 형성된 종목만 선별.
    - **수급 컨펌 (거래량):** 최근 20일 평균 거래량 대비 **150% 이상의 거래량 폭증**이 확인된 경우만 승인.

### 2.3 Alpha 리더보드 (Source Reliability)
- **용도:** "누가 가장 잘 맞추는가?"에 대한 답을 제공합니다.
- **분석 대상:** '당잠사', '매드머니', 'CNBC', 'Bloomberg' 등 각 정보 소스별 적중률(Hit Ratio)과 평균 초과 수익률을 랭킹화합니다.
- **차별화:** 단순 정보 나열을 넘어 정보원의 신뢰도를 데이터로 증명하여 투자자의 의사결정을 돕습니다.

### 2.4 A/B 비교 분석 (Comparison Analysis)
- **용도:** 순수 뉴스 시그널과 필터 통과 시그널의 성과를 직접 비교합니다.
- **핵심 지표:**
    - **개선도 (Alpha Boost):** 필터 적용 전후의 평균 초과 수익률 차이.
    - **적중률 (Hit Ratio) 변화:** 양(+)의 초과 수익률을 기록한 시그널의 비율 변화.

## 3. 주요 분석 지표 (Key Metrics)

| 지표명 | 설명 | 비고 |
| :--- | :--- | :--- |
| **초과 수익률 (Alpha)** | 벤치마크(예: SOXX, S&P500) 대비 종목의 상대적 수익률 | T+3, T+5, T+20일 기준 |
| **적중률 (Hit Ratio)** | 초과 수익률이 0보다 큰 시그널의 비율 | 소스별/전략별 신뢰도 지표 |
| **이벤트 스터디 (Event Study)** | 시그널 발생 시점(T=0)부터 이후 20일까지의 누적 수익률 추이 | Alpha 감쇠(Decay) 분석 |

## 4. 고도화 분석 엔진 (Institutional-Grade Analysis)

### 4.1 Regime Engine (시장 국면 분석)
- **개념:** 현재 시장이 상승장(Bull), 하락장(Bear), 혹은 회복기(Recovery)인지 구분하여 시그널을 필터링합니다.
- **효과:** 시장 국면에 따라 동일한 시그널도 다르게 해석하여 하락장에서의 가짜 시그널(False Positive)을 제거합니다.

### 4.2 Alpha Decay Analysis (수익률 감쇠 분석)
- **개념:** 시그널 발생 후 시간이 지남에 따라 초과 수익률이 어떻게 변하는지 추적합니다.
- **효과:** 해당 정보가 단기성 재료인지, 장기적 추세를 만드는 재료인지 구분하여 최적의 매도 타이밍(Exit Strategy)을 제시합니다.

## 5. 디자인 원칙 (Design Principles)
- **고밀도 UI:** 불필요한 공백을 최소화하고 정보를 한눈에 파악할 수 있도록 설계 (본문 폰트 18px 기준).
- **시각적 언어:** 상승은 **빨간색**, 하락은 **파란색**으로 표시하며, 필터링된 결과는 **오렌지색** 포인트 컬러를 사용하여 강조합니다.
- **한국어 우선:** 모든 전문 용어는 쉬운 한국어로 번역하여 제공합니다 (예: Alpha -> 초과 수익률).
