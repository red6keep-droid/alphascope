# AlphaFlow 애플리케이션 상세 명세서 (App Specification)

## 1. 개요 (App Purpose)
**AlphaFlow**는 인공지능(Gemini)을 활용하여 다양한 금융 미디어(유튜브 자막, 뉴스 브리핑 등)로부터 투자 시그널을 추출하고, 이를 퀀트 데이터로 검증하여 투자자에게 실전적인 인사이트를 제공하는 **지능형 전략 분석 시스템**입니다.

### 핵심 가치
- **정보의 구조화:** 방대한 영상 자막과 텍스트 데이터를 AI가 분석하여 종목, 내러티브, 심리 상태로 요약.
- **퀀트 기반 검증:** AI가 추출한 시그널이 실제 시장에서 유효했는지 백테스트(T+N 수익률) 및 기술적 지표(거래량 등)로 즉각 검증.
- **직관적 모바일 경험:** 한국인 투자자에게 최적화된 고밀도 UI와 쉬운 용어 사용.

---

## 2. 시스템 구조 (System Architecture)

### 2.1 기술 스택 (Tech Stack)
- **Frontend:** React 19, Vite, Tailwind CSS (v4), Motion (애니메이션), Recharts (차트).
- **Backend:** Node.js, Express, tsx (실행 엔진).
- **AI/ML:** Google Gemini (1.5 Flash / 2.0 Flash) - 구조화된 JSON 응답 추출.
- **Database/Storage:** Firebase Firestore (분석 결과 저장), Firebase Storage (텍스트 데이터 관리).
- **Financial Data:** Yahoo Finance API (실시간 시세 및 과거 주가 데이터).

### 2.2 폴더 구조 (Project Structure)
- `doc/`: 프로젝트 문서 및 가이드라인.
- `src/`: 프론트엔드 소스 코드.
- `src/components/`: 재사용 가능한 UI 컴포넌트 (`TickerInsights` 등).
- `src/engine/`: AI 분석 엔진 연동 로직 (`AnalysisEngine`).
- `server.ts`: 백엔드 API 서버 (AI 분석, 데이터베이스 연동, 금융 데이터 수집).
- `functions/`: 클라우드 백그라운드 작업 및 스케줄러.

## 3. 핵심 기능 및 코드 로직 (Core Features)

### 3.1 AI 내러티브 추출 (AI Analysis)
[`server.ts`](../server.ts)의 AI 프롬프트는 텍스트 데이터에서 다음 항목을 정밀하게 추출합니다:
- **종목명 및 티커:** 언급된 기업 식별.
- **내러티브:** 해당 종목이 상승/하락하는 논리적 근거.
- **시장 심리:** 상승(Bullish) / 하락(Bearish) / 중립(Neutral).
- **마켓 카탈리스트:** 향후 예정된 주요 일정(D-Day) 및 설명.

### 3.2 퀀트 승인 엔진 (Quant Validation)
추출된 시그널은 즉시 다음 필터를 통과해야 합니다:
- **초과 수익률(Alpha) 계산:** 벤치마크(예: SOXX, S&P 500) 대비 T+0~T+14일간의 상대 수익률 산출.
- **거시 지표 필터:** VIX 지수 25 미만 조건 확인.
- **기술적 지표 필터:** 최근 20일 평균 거래량 대비 150% 이상의 거래량 폭증 여부 확인.

### 3.3 네트워크 확산 점수 (Spread Score)
서로 다른 채널(예: '당잠사'와 '매드머니')에서 동일한 종목과 내러티브가 동시에 언급될 경우, 시장의 합의(Consensus)가 형성된 것으로 간주하여 '확산 점수'를 높게 부여하고 상단에 배치합니다.

### 3.4 고밀도 UI (High-Density Design)
- 모든 폰트 크기를 **18px**로 통일하여 가독성 확보.
- 불필요한 공백을 제거하고 정보를 한 줄에 압축적으로 표시.
- 한국 시장 표준 컬러 적용 (상승: 빨강, 하락: 파랑).

## 4. 향후 확장 계획 (Roadmap)
- **실시간 뉴스 피드 통합:** 유튜브 자막 외에 실시간 뉴스 API 연동.
- **포트폴리오 시뮬레이션:** 추출된 시그널을 바탕으로 가상 포트폴리오 성과 추적.
- **알림 서비스:** 주요 카탈리스트(D-Day) 도래 시 푸시 알림 제공.
