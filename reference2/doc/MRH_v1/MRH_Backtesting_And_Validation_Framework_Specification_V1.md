# MRH (Momentum Rotation Hunter)

# MRH_Backtesting_And_Validation_Framework_Specification_V1

# 백테스트 및 검증 프레임워크 명세서

---

# 제1장. Backtesting 철학

## 1.1 핵심 철학
MRH의 백테스트 목적은:

```
"천재 전략 증명"
```
이 아니다.

실제 목적은:

```
실전에서
망가지지 않을 가능성 확인
```
이다.

---

# 1.2 가장 중요한 원칙
MRH는:

```
백테스트 수익률
```
을 과신하지 않는다.

왜냐하면 실제 시장에는:

- 슬리피지
- gap down
- false breakout
- delayed fill
- 심리적 흔들림
- API 오류

가 존재하기 때문이다.

---

# 1.3 핵심 목표
MRH 백테스트 핵심:

```
과최적화 방지
+
생존 가능성 검증
```

---

# 제2장. 백테스트 시스템 구조

# 2.1 전체 흐름

```
과거 데이터 로드
↓
후보 생성
↓
Ranking 계산
↓
매수/매도 시뮬레이션
↓
수수료 반영
↓
성능 기록
↓
리스크 분석
```

---

# 제3장. 핵심 검증 기준

# 3.1 가장 중요한 질문
MRH 핵심 질문:

```
정말 SPY Buy & Hold보다
의미 있는 장점이 있는가?
```

---

# 3.2 단순 CAGR 집착 금지
MRH는:

```
CAGR 하나만
성공 기준으로 보지 않는다
```

---

# 3.3 핵심 비교 항목
| 항목 | 중요도 |
| :--- | :--- |
| CAGR | 높음 |
| MDD | 매우 높음 |
| Recovery Time | 매우 높음 |
| Ulcer Index | 높음 |
| Exposure-adjusted Return | 높음 |
| Slippage-adjusted CAGR | 매우 높음 |

---

# 제4장. 실제 수수료 반영

# 4.1 필수 원칙
수수료 없는 백테스트:

```
의미 없음
```

---

# 4.2 실제 반영 구조
사용자 제공 거래소 기준 적용.

---

# 4.3 반영 항목
| 항목 | 적용 |
| :--- | :--- |
| 매수 수수료 | 적용 |
| 매도 수수료 | 적용 |
| 슬리피지 | 적용 |
| 환율 | 초기 MVP 제외 |

---

# 4.4 슬리피지 기본값
| 상황 | 기본값 |
| :--- | :--- |
| 일반 종목 | 0.1~0.2% |
| 고변동 급등주 | 0.3~0.8% |

---

# 제5장. 실제 진입 규칙 반영

# 5.1 중요한 원칙
MRH는:

```
당일 고점 체결
```
같은 비현실적 체결 금지.

---

# 5.2 기본 체결 방식
| 방식 | 적용 |
| :--- | :--- |
| 다음날 시가 | 기본 |
| 종가 진입 | 선택 가능 |

---

# 제6장. Walk-Forward Validation

# 6.1 목적

```
과거 데이터 암기 방지
```

---

# 6.2 핵심 구조

```
과거 구간 학습
↓
미래 구간 검증
↓
반복
```

---

# 6.3 금지 사항
금지:

- 전체 데이터 최적화
- 미래 데이터 참조
- hindsight fitting

---

# 제7장. 핵심 위험 구간 검증

# 7.1 반드시 테스트할 시장
| 시장 | 중요도 |
| :--- | :--- |
| 2008 금융위기 | 매우 중요 |
| 2020 코로나 | 매우 중요 |
| 2022 인플레 장세 | 매우 중요 |
| 횡보장 | 매우 중요 |

---

# 7.2 이유
MRH는:

```
상승장 수익률
```
보다:

```
애매한 시장에서
얼마나 덜 망가지는가
```
가 더 중요.

---

# 제8장. Whipsaw 분석

# 8.1 매우 중요
실제 시스템을 죽이는 건:

```
반복적 false signal
```
이다.

---

# 8.2 반드시 기록할 항목
| 항목 | 설명 |
| :--- | :--- |
| False Crisis Ratio | 잘못된 Risk OFF |
| Re-entry Lag | 재진입 지연 |
| Missed Rebound | 반등 놓침 |
| Switching Frequency | 체제 전환 빈도 |

---

# 제9장. Turnover Leakage 분석

# 9.1 핵심 중요성
실전에서는:

```
과도한 회전율
```
이 CAGR 대부분을 파괴 가능.

---

# 9.2 기록 항목
| 항목 | 목적 |
| :--- | :--- |
| 월 turnover | 측정 |
| 연 turnover | 측정 |
| 평균 보유기간 | 측정 |
| 거래당 비용 | 측정 |

---

# 제10장. Recovery Delay 분석

# 10.1 목적

```
너무 늦은 재진입 확인
```

---

# 10.2 핵심 이유
Continuation 시스템은:

- 하락 회피 가능
- 대신 반등 놓칠 위험 존재

---

# 10.3 기록 항목
| 항목 | 설명 |
| :--- | :--- |
| rebound miss % | 측정 |
| recovery delay | 측정 |
| V-shape miss | 기록 |

---

# 제15장. MVP에서 하지 않는 것

- intraday simulation

---

# 제16장. Backtesting 시스템의 진짜 역할
MRH Backtesting 시스템은:

```
미래 수익 보장 도구
```
가 아니다.

실제 역할은:

```
이 전략이
실전에서 얼마나 쉽게 망가질 수 있는지
미리 확인하는 것
```
이다.
