# MRH (Momentum Rotation Hunter)

# MRH_Position_Management_And_Risk_Control_Specification_V1

# 포지션 관리 및 리스크 제어 명세서

---

# 제1장. Position Management 철학

## 1.1 핵심 철학
MRH의 핵심은:

```
승률 극대화
```
가 아니다.

실제 핵심은:

```
손실 제한
+
강한 winner 지속 보유
```
이다.

---

# 1.2 시스템 본질
MRH는:

```
높은 승률 시스템
```
이 아니다.

실제로는:

```
작은 손실 반복
+
큰 상승 1~2개 확보
```
구조를 추구한다.

---

# 제2장. 전체 구조

# 2.1 핵심 흐름

```
매수
↓
초기 리스크 제한
↓
상승 continuation 추적
↓
손절 or trailing exit
```

---

# 제3장. Position Size 구조

# 3.1 핵심 원칙
MRH는:

```
한 종목에 계좌 운명 걸기
```
를 금지한다.

---

# 3.2 최대 보유 종목 수
| 상태 | 최대 |
| :--- | :--- |
| 일반 | 3개 |
| 공격적 | 5개 이하 |

---

# 3.3 단일 포지션 제한
| 항목 | 제한 |
| :--- | :--- |
| 최대 비중 | 20% |
| 권장 비중 | 10~15% |

---

# 3.4 이유
Continuation 전략 특성상:

```
급락 리스크
+
gap down
```
위험이 존재.

따라서:

```
생존 우선
```
원칙 유지.

---

# 제4장. 진입 구조

# 4.1 기본 진입 시점
기본 원칙:

```
미국 장 마감 후 신호 생성
↓
다음 거래일 진입 판단
```

---

# 4.2 진입 방식
| 방식 | 설명 |
| :--- | :--- |
| 종가 매수 | 기본 |
| 다음날 초반 확인 | 선택 가능 |

---

# 제5장. 손절 구조

# 5.1 손절 철학
MRH에서 가장 중요한 건:

```
큰 손실 방지
```
이다.

---

# 5.2 왜 고정 손절이 필요한가
Continuation 전략은:

```
틀렸을 때 빠르게 실패 인정
```
해야 함.

---

# 5.3 기본 손절 기준
| 전략 | 손절 |
| :--- | :--- |
| 기본 continuation | -5% |
| 강한 momentum | -4% |
| 고변동 종목 | -6% |

---

# 5.4 절대 금지 사항
금지:

- 물타기
- 손절 무시
- 장기 존버 전환
- “다시 오를 것” 기대

---

# 제6장. Trailing Exit 구조

# 6.1 목적

```
상승은 최대한 열어두기
```

---

# 6.2 핵심 철학
MRH 수익 대부분은:

```
소수의 강한 winner
```
에서 발생.

---

# 6.3 Trailing 구조
| 상태 | 행동 |
| :--- | :--- |
| +5% 이상 | 손절 상향 가능 |
| +10% 이상 | trailing 강화 |
| 급락 발생 | 청산 고려 |

---

# 6.4 핵심 논리

```
손실은 짧게
수익은 길게
```

---

# 제7장. Time Stop 구조

# 7.1 목적

```
죽은 포지션 제거
```

---

# 7.2 기본 규칙
| 조건 | 행동 |
| :--- | :--- |
| 5거래일 횡보 | 관찰 |
| 7거래일 무의미 | 청산 고려 |
| 10거래일 이상 | 기본 청산 |

---

# 7.3 이유
MRH는:

```
짧은 continuation
```
을 추적.

따라서:

```
상승 에너지 소멸
```
은 중요.

---

# 제8장. Gap Down 대응

# 8.1 핵심 위험
Continuation 전략 최대 위험:

```
overnight gap down
```

---

# 8.2 대응 원칙
| 상황 | 행동 |
| :--- | :--- |
| -3% gap | 경계 |
| -5% gap | 즉시 검토 |
| -8% 이상 | 강제 청산 가능 |

---

# 제9장. Exposure 구조

# 9.1 핵심 철학
MRH는:

```
항상 풀베팅
```
하지 않는다.

---

# 9.2 총 노출도 제한
| 시장 상태 | 노출 |
| :--- | :--- |
| 강세 | 70~80% |
| 중립 | 30~50% |
| 위험 | 0~20% |

---

# 9.3 현금 유지 목적

```
급락 생존
+
재진입 여력 확보
```

---

# 제10장. Re-Entry 금지 규칙

# 10.1 목적

```
같은 종목 반복 손실 방지
```

---

# 10.2 규칙
| 조건 | 행동 |
| :--- | :--- |
| 손절 직후 | 재진입 금지 |
| 최소 3일 | 대기 |
| 새 breakout 발생 | 재평가 가능 |

---

# 제11장. Sector Concentration 제한

# 11.1 핵심 이유
미국 시장은:

```
tech concentration
```
강함.

---

# 11.2 제한 규칙
| 항목 | 제한 |
| :--- | :--- |
| 동일 섹터 | 최대 40% |
| 동일 테마 | 과집중 금지 |

---

# 제12장. No Trade 상태

# 12.1 매우 중요
MRH 핵심 능력 중 하나:

```
아무것도 안 하는 것
```

---

# 12.2 신규 진입 금지 조건
| 조건 | 행동 |
| :--- | :--- |
| 시장 혼조 | 진입 제한 |
| 후보 부족 | 현금 유지 |
| 점수 약함 | HOLD |

---

# 제13장. Emergency Risk OFF

# 13.1 목적

```
시장 붕괴 생존
```

---

# 13.2 발동 조건
| 조건 | 행동 |
| :--- | :--- |
| SPY 급락 | 축소 |
| VIX 급등 | 경계 |
| HYG + RSP 붕괴 | 강한 OFF |

---

# 13.3 핵심 원칙

```
Risk OFF는
Risk ON보다 빨라야 한다
```

---

# 제14장. 실제 운영 핵심

# 14.1 중요한 사실
MRH의 핵심은:

```
매번 맞추기
```
가 아니다.

---

# 14.2 실제 핵심

```
작게 여러 번 틀리고
크게 한 번 먹기
```
구조 유지.

---

# 제15장. 실제 위험 인정
MRH는 다음을 인정한다:

- false breakout
- fake continuation
- gap down
- V-shape reversal
- whipsaw

완벽 회피는 불가능.

---

# 제16장. MVP에서 하지 않는 것
초기 MVP 제외:

- 자동 주문
- intraday trading
- options hedge
- leverage trading
- martingale
- averaging down

---

# 제17장. Position Engine의 진짜 역할
MRH Position Engine은:

```
수익 극대화 시스템
```
이 아니다.

실제 역할은:

```
작은 손실로 생존하면서
강한 continuation winner를
최대한 오래 추적하는 것
```
이다.
