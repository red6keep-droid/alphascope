# MRH (Momentum Rotation Hunter)

# MRH_Operational_Runtime_And_Daily_Workflow_Specification_V1

# 실제 운영 런타임 및 일일 운영 워크플로우 명세서

---

# 제1장. Operational Runtime 철학

## 1.1 핵심 철학
MRH는:

```
하루 종일 차트를 보는 트레이딩 시스템
```
이 아니다.

실제 목표는:

```
매일 30~60분 이내로
운영 가능한 시스템
```
이다.

---

# 1.2 운영 구조 핵심
MRH는:

```
자동매매 시스템
```
이 아니다.

구조는:

```
시스템이 후보 추천
↓
사용자가 직접 매수/매도 실행
```
이다.

---

# 1.3 인간 역할 유지 이유
MRH는 다음을 인정한다:

- 무료 데이터 한계
- 급등주 노이즈
- API 오류
- 비정상 spike
- 시장 이벤트

따라서:

```
최종 실행은 사람 확인 유지
```
원칙 채택.

---

# 제2장. Daily Runtime 구조

# 2.1 전체 운영 흐름

```
미국 장 종료
↓
자동 데이터 수집
↓
Ranking 계산
↓
매수/매도 후보 생성
↓
모바일 알림 발송
↓
사용자 확인
↓
다음 거래일 실행
```

---

# 제3장. 실제 하루 운영 루틴

# 3.1 미국 장 종료 후
자동 실행:

| 작업 | 설명 |
| :--- | :--- |
| 후보 수집 | 급등주 추출 |
| OHLCV 저장 | snapshot |
| Ranking 계산 | continuation score |
| 기존 포지션 점검 | sell 조건 검사 |

---

# 3.2 최종 결과 생성
최종 생성:

```
오늘의 BUY 후보
+
SELL 후보
+
시장 위험 상태
```

---

# 제4장. 모바일 알림 구조

# 4.1 핵심 목적
MRH 핵심은:

```
복잡한 분석 화면
```
이 아니다.

실제 목적은:

```
빠른 의사결정
```
이다.

---

# 4.2 BUY 알림 예시

```
[MRH BUY SIGNAL]

Ticker: NVDA
Score: 87

Reason:
- Strong continuation
- RVOL 3.2
- Sector strong
- Close near high

Suggested Stop:
-5%

Risk Level:
Moderate
```

---

# 4.3 SELL 알림 예시

```
[MRH SELL SIGNAL]

Ticker: AMD

Reason:
- Stop loss triggered
- Momentum weakening
- Close weakness detected
```

# 제9장. 현금 유지 철학

# 9.1 매우 중요

```

아무것도 안 하는 것
```

---

# 9.2 현금은 실패가 아님
현금은:

- 리스크 관리
- 다음 기회 준비
- 심리 안정
- 급락 생존

역할 수행.

# {17장}. Runtime 시스템의 진짜 역할
MRH Runtime 시스템은:

```
자동 부자 시스템
```
이 아니다.

실제 역할은:

```
매일 시장에서
가장 강한 continuation 후보를
간단하고 지속 가능하게 운영하도록 돕는 것
```
이다.
