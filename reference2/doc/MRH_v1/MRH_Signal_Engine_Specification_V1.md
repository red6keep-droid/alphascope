# MRH (Momentum Rotation Hunter)

# Signal Engine Specification V1

# 공격형 Continuation Momentum 엔진 명세서

---

# 제1장. 엔진 정체성

## 1.1 엔진 목적

MRH Signal Engine의 목적은:

> **미국 시장에서 이미 강하게 움직이기 시작한 종목 중 "다음 며칠 동안 추가 상승 가능성이 높은 종목"만 압축 탐지하는 것**

이다.

본 엔진은:
* 저점 예측 엔진
* 가치평가 엔진
* AI 미래예측 엔진

이 아니다.

핵심은:
> **강한 continuation 흐름 추적**

이다.

---

# 제2장. 전략 철학

## 2.1 핵심 철학

MRH는:
> **Winner를 빠르게 발견하고 짧게 탑승하고 빠르게 교체한다**

를 목표로 한다.

---

## 2.2 전략 구조

전략 본질:

| 요소 | 목적 |
| :--- | :--- |
| Momentum | 강한 종목 탐지 |
| Continuation | 추가 상승 가능성 탐지 |
| Rotation | 약해지면 빠르게 교체 |
| Tight Stop | 대형 손실 차단 |

---

## 2.3 평균 보유 기간

목표 평균 보유 기간:

| 상태 | 기간 |
| :--- | :--- |
| 일반 | 3~7 거래일 |
| 최대 | 1.5주 |
| 예외 | 2주 이내 |

# 제4장. 외부 데이터 플랫폼

## 4.1 외부 플랫폼 역할

외부 플랫폼은:
> **1차 급등 후보 수집기**

역할을 한다.

MRH는:
* 직접 전체 시장 스캔보다
* 이미 강한 종목 후보를 외부에서 공급받는다.

---

## 4.2 무료 기반 MVP 구조

MVP 기준:

| 역할 | 플랫폼 |
| :--- | :--- |
| 가격 데이터 | Yahoo Finance |
| 미국 종목 정보 | Finnhub Free |
| 시장 데이터 | KIS |
| 급등 후보 | TradingView Scanner |
| 뉴스 확인 | Finviz 무료 |

---

## 4.3 핵심 철학

MRH의 핵심은:
> **종목 수집 자체가 아니라 수집된 강한 종목 중 진짜 continuation 가능성만 재평가하는 것**

이다.

# 제8장. 매수 실행 규칙

* 미국 장 종료 후 확인

한다.

| :--- | :--- |

우선.

# 제14장. 시스템의 현실적 한계

MRH는:
> **미래를 예측하지 못한다**

또한:
* false breakout 발생
* whipsaw 발생
* rebound miss 발생

은 필연적이다.

핵심은:
> **작은 실패를 반복하면서 큰 winner를 짧게 먹는 구조**

를 유지하는 것이다.
