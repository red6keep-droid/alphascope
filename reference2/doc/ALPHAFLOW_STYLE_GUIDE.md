## 3. 여백 시스템 (Spacing)
`prototype/css/utilities.css` 및 `layout.css`에 정의되어 있습니다.

### 3.1 섹션 간격 (Structural)
- **`.section-wrapper`**: `padding: 6px 11px` (모바일 최적화 고밀도 간격)
- **표준 통합 여백**: `.mb-12` 또는 `.mt-12` 사용 (12px)
- **적용 대상**: 탭 하단, 헤더 하단, 섹션 타이틀 상단

### 3.2 마진 및 패딩 유틸리티 (Spacing)
| 클래스명 | 간격값 | 용도 |
| :--- | :--- | :--- |
| `.mb-2`, `.mt-2`, `.ml-2`, `.mr-2` | 2px | 초미세 간격 (수치 옆, 텍스트 사이 등) |
| `.py-2`, `.py-4` | 2px / 4px | 초미세 상하 패딩 (테이블 헤더 등) |
| `.mb-4`, `.mt-4`, `.ml-4`, `.mr-4` | 4px | 아주 좁은 요소 간격 |
| `.mb-8`, `.mt-8`, `.ml-8` | 8px | 일반적인 요소 간격 |
| `.mb-12`, `.mt-12` | 12px | 헤더, 탭, 섹션 내 큰 덩어리 표준 간격 |
| `.mb-24`, `.mt-24` | 24px | 페이지 내 주요 영역 구분 |
| `.mb-32`, `.mt-32` | 32px | 하단 버튼 위쪽 등 큰 구분 |
| `.p-16`, `.py-16` | 16px | 리스트 아이템, 설정 항목 내부 패딩 |
| `.px-0` | 0px | 좌우 패딩 제거 (섹션 내 정렬용) |
| `.px-11` | 11px | 모바일 표준 좌우 여백 (섹션 내부용) |
| `.py-20`, `.py-40` | 20px / 40px | 페이지 상하단 큰 여백 및 안내 문구용 |

### 3.3 간격 유틸리티 (Gap)
- **`.gap-2`**: 2px 간격
- **`.gap-4`**: 4px 간격 (홈 종목 리스트 버튼 간격 등)
- **`.gap-8`**: 8px 간격

### 3.4 텍스트 정렬 (Alignment)
- **`.text-center`**: 텍스트 중앙 정렬
- **`.text-right`**: 텍스트 우측 정렬

### 3.5 표준 데이터 테이블 (Standard Table)
고밀도 정보 나열을 위해 다음 구조를 표준으로 사용한다.
- **컨테이너**: `.w-full`
- **헤더 (Optional)**: `.divider-1px`로 상하 구분 + `.py-4` 여백 적용
- **데이터 행**: `.py-4` 또는 `.py-12` 적용 + 하단 `.divider-1px` 또는 `border-bottom` 사용
- **비율 배분**: `flex` (3:2:4 등)를 사용하여 모바일 너비 최적화

#### 3.5.1 미니멀 테이블 (Minimal Variation)
- **헤더 생략**: "종목 / 현재가"와 같은 타이틀 영역을 완전히 삭제하여 공간을 극대화한다.
- **오픈형 하단**: 섹션의 마지막에 위치할 경우, **마지막 행의 하단 선(Border-bottom)을 삭제**하여 다음 섹션과의 연결을 자연스럽게 한다.
- **상단 구분**: 테이블이 시작되는 지점에만 `.divider-1px`를 배치하여 영역을 구분한다.

### 3.6 구분선 및 박스 (Dividers & Boxes)
- **`.divider-1px`**: 좌우 여백 없는 1px 실선 (영역 구분용)
- **`.divider-5px`**: 회색 배경의 5px 두께 바 (강력한 섹션 구분용)
- **`.highlight-banner`**: 연한 블루 배경에 5px 구분선과 동일한 컬러의 50% 투명도 테두리 적용 (주요 수치 강조용)
- **`.guide-box`**: 연한 그레이 배경(#F8FAFC)에 회색 점선 테두리(#CBD5E1)를 가진 안내 영역 박스 (원칙, 주의사항, 가이드용)
- **`.warning-box`**: 연한 레드 배경(#FFF5F5)에 레드 테두리(rgba(239, 68, 68, 0.3))를 가진 경고 영역 박스 (기회 비용 발생 주의, 시간 손절 등 시스템 경고용)

`prototype/css/buttons.css` 및 `detail.css`에 정의되어 있습니다.

- **`.btn-back-header`**: 상세 페이지용 28x28 원형 뒤로가기 버튼

## 6. 디자인 금지 및 권장 사항 (Constraints)
- **금지**: 어두운 배경(Dark Background) 카드 사용 금지.
- **인라인 스타일 금지**: 모든 스타일은 공통 클래스를 사용하며, HTML 태그 내 `style="..."` 속성 사용을 금지한다.
- **신규 페이지 원칙**: 모든 신규 페이지는 반드시 프로젝트의 공통 UI 클래스를 재사용하여 디자인 일관성을 유지한다.
- **권장**: 주요 지표 강조 시 `.highlight-banner` (Light Blue) 사용.
- **증감 표기**: 모든 수치 증감은 반드시 `.up` (Red), `.down` (Blue) 클래스를 적용한다.

## 7. 핵심 화면 구성 (Screens)
- **홈 (Home)**: `알파종목`, `최신뉴스`, `보유자산` 탭 구성.
- **시장 상황 판독 (Regime)**: HMM 국면 및 매크로 지표 시각화.
- **알파 인텔리전스 (Intelligence)**: 정보원 신뢰도 리더보드, 데이터 정제 깔때기(Funnel), A/B 성과 비교.
- **알림 센터 (Notifications)**: 실시간 투자 시그널 알림 리스트.
- **설정 (Settings)**: 앱 환경 설정 및 사용자 프로필.

---

## 8. 주요 지표 정의 (Metric Definitions)
- **평균 초과 수익 (Average Alpha)**: 특정 정보원이 언급한 종목들의 수익률에서 시장 지수(Benchmark) 수익률을 뺀 값의 평균. 정보원의 정량적 성과를 의미함.
- **적중률 (Hit Ratio)**: 전체 언급 종목 중 시장 대비 플러스(+) 초과 수익을 기록한 종목의 비율. 시그널의 신뢰도를 의미함.
